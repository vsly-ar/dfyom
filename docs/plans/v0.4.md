## Questions for the user

Each with a recommendation; "Q28 ok" takes it. Numbering continues after the v0.3 docs' Q27.

1. **Q28 – Scope.** v0.4 = the feature model + the **hole** feature (simple, counterbore, countersink) + **Clones** v1 (one face, no rotation, stable numbering) + what countersinks need: a **chamfer operation on circular edges** and a **chamfer mill / V-bit** tool type. Later: chamfers along any shape (the enclosure bevel), the Field info views framework, decorative patterns. _Recommendation: yes._ Why: the bolt circle of counterbored holes is the first real use of both features (C7), countersinks are the most common screw hole after counterbores, and the circular chamfer is the smallest new cut that makes them possible; edge chamfers along shapes need a geometry spike first (S7), and Field info views are an L-sized UI framework that would double the milestone.
2. **Q29 – Hole standards.** ISO metric M2–M12 in v0.4 (clearance ISO 273 close/normal/loose, tap drills, ISO 4762 socket head counterbores, ISO 10642 90° countersinks); inch (#4–1/2″, 82°) right after; custom sizes always. Threads are never cut: "threaded" = a tap drill hole for tapping by hand, or a custom pilot for an insert. _Recommendation: yes._
3. **Q30 – Repetition is Clones; "pattern" stays yours.** Linear, grid and bolt-circle repetition are Clones rows (`grid`, `offset`, `polar`, `arc`, `point`); the word "pattern" stays reserved for the decorative patterns you meant (cnc-code's pattern helper, D30), later. Add an **`along`** row (positions at a spacing along a named shape's path, orientation kept) to v0.4, first to cut. _Recommendation: yes to both._
4. **Q31 – Clones C3/C4/C6.** Clone instances always use the source operation's tool (read-only, one tool change); removing a Clones feature keeps its source; Clones are made only from existing operations or a feature ("Make Clones…" on a selection), never with a blank source. _Recommendation: as written (the features.md recommendations)._
5. **Q32 – `tools/list` budget (1.2 K left of 100 K; v0.4 adds ≈ 11–14 K).** Options: **A** raise to 120 K (≈ 30 K tokens; cheap, costs every agent context); **B** consolidate: one `design.feature.add`/`update` with a `kind` union and the per-kind operation `add`/`update` tools merged into `design.operation.add`/`update` (saves ≈ 15–20 K, but a breaking agent-API change and a large refactor); **C** a default `--areas` profile that leaves library editing and rare tools out until a session tool enables them (saves ≈ 20 K in the default list, agents can miss tools). _Recommendation: A now (120 K, with the small folds already in design-v0.4: `feature.get` into `list`), and plan B as the lever before v0.5 if LLM-first sessions (B14) show context pressure._
6. **Q33 – One tool type for chamfer mills and V-bits** (`chamferMill`: diameter, included angle, tip diameter), plunged at the hole centre when it covers the countersink, else run round it. _Recommendation: yes; engraving and V-carving reuse it later._
7. **Q34 – Exit part: a lid for the v0.3 enclosure** ([Exit criteria](#exit-criteria)): the same oval outline, four countersunk M3 holes over the base's blind holes (Clones grid of one hole), a connector cutout with a bolt circle of six counterbored M3 holes (Clones arc), a row of vent slots (Clones of a pocket, one position skipped). _Recommendation: yes._
8. **Q35 – X2 leftovers in v0.4.** Fix the three small v0.3 UI findings ("Round corners" offers the largest radius the corner takes; an open path on an Outside profile offers "Use side On"; typing a tab position during an arrow-key run is not overwritten); defer the rest ([Known issues](#known-issues-carried-over)). _Recommendation: yes._

## Exit criteria

The test part is a **lid for the v0.3 enclosure** ([v0.3 exit part](v0.3.md#exit-criteria)): a 255 × 185 × 6 mm plywood board; outline = the enclosure's outline shape from `enclosure-sections.svg` (the v0.3 fixture), cut as an outside profile with tabs; on the top face:

- **Four countersunk M3 clearance holes** at (±88.5, ±44.3) mm from the centre, over the base's four blind holes: one hole feature (`countersink`, M3, `normal` fit: Ø 3.4, ISO 10642 head) at (−88.5, −44.3) and a Clones `grid` row 2 × 2 with spacing 177 × 88.6.
- **A connector cutout with a bolt circle:** a Ø 22 through circular pocket at (60, 0); one counterbored M3 hole (ISO 4762) 17 mm to its right; a Clones `arc` row round the cutout's centre, 360° every 60° → 6 holes.
- **Six vent slots:** an obround through pocket 30 × 5 mm at (−60, −30) and a Clones `offset` row of 6 more with step (0, 10); instance 4 skipped (a label area) → 6 slots, numbered 1–3 and 5–7.

Flows:

- **In the app** (the golden path, [X2](#7-acceptance)): new project; Import SVG… the sections and keep the outline; the outline profile with four tabs; add the countersunk hole through "Add › Features › Hole" with the fastener picker; Make Clones… grid; the cutout pocket, the counterbored hole and the arc Clones; the vent pocket and its Clones, skipping instance 4 by clicking it; change the bolt-circle source from M3 to M4 (the Apply button counts **1** change; all four instances follow); Apply. Plan derives one setup; generate; the program changes tool **once per distinct tool** (chamfer mill once, not four times) and comments name clone positions; export; run on the virtual machine. Save, close, reopen: features, clone rows, skips and instance ids unchanged; undo of the M3 → M4 change restores all instances in one step.
- **The same flow headless** through MCP and `dfyom batch` ([X1](#7-acceptance)) with `design.hole.*`, `design.clones.*` (`preview` first), `design.fastener.list`, golden programs, and a geometry check (test-only): the evaluated part has 10 screw holes (4 with cones, 6 with counterbores), the cutout and 6 slots at the stated positions within 0.01 mm.
- `npm run check` and the e2e suite green in CI; `tools/list` within the budget decided by Q32.
