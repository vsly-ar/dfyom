# v0.1 plan – 2.5D basics to the virtual machine

Status: accepted · Scope: [roadmap.md#v01](../roadmap.md#v01--25d-basics-to-the-virtual-machine) · Last updated: 2026-11-17

**Living document.** Update it in the same commit as the work: change a task's status, add tasks you discover, record issues. Scope changes go to the [roadmap](../roadmap.md) first.

Status values: `done` · `doing` · `todo` · `blocked` (say on what) · `dropped` (say why).

## Next up

1. Persistence (task 3.1).
2. Library models and design operations in core (tasks 2.4, 2.5).
3. Evaluation checks (task 2.8); feeds-and-speeds calculator (task 2.12).

## Exit criteria

- In the app: create a project with a rectangular stock, add facing, pocket (inside corner radius, floor fillet), drilling and profile with tabs; plan one setup; export GRBL gCode; run it on the virtual machine with progress shown; save, close and reopen the project.
- The same flow driven entirely through MCP/CLI, headless, as an automated end-to-end test.
- `npm run check` (typecheck, lint, tests) green in CI.
