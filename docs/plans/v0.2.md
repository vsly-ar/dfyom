## Exit criteria

- **In the app** (the golden path, [X2](#6-acceptance)): new project; import an STL reference of the test part, read as mm, fit to the stock (centre, top), hide and show it; recreate the part: a facing and a pocket on the top (the pocket positioned by its front-left corner), a drilling on the right side face (`+x`), a pocket on the bottom; lock a library tool on one operation and leave the others to the auto choice; apply with Enter and with the Apply button. Plan derives three setups (bottom, right, top last); settle the design, edit one operation for this plan only and see it in the plan scene; edit a strategy parameter; generate; export one GRBL program per setup; run every program on the virtual machine with the setup-change prompt between them. Save, close and reopen: the reference, anchors, tools and setups are unchanged. **Done** (X2): `e2e/golden-path-v0.2.e2e.ts` runs the flow through the UI, hidden windows ([testing.md](../conventions/testing.md#app-playwright-for-electron)); the library starts empty, so the tools come from Plan's "New tool…" first and the library's Flat 12 is then locked on the profile with the design's tool field, which the draft plan takes from the design.
- **The same flow driven entirely through MCP/CLI**, headless, as an automated end-to-end test ([X1](#6-acceptance)), including `design.reference.import` from the STL file. **Done** (X1): `src/main/cli/exit-criteria.v02.fixture.ts`; the in-app steps without a headless counterpart (Enter/Apply button, hide and show the reference) are X2's.
- **Spike S1** has an ADR (proposed) with measurements for the v0.3 2D library.
- `npm run check` and the e2e suite green in CI.
