# Glossary

Status: draft

Industry-standard terms as used in DFYOM. This list seeds the in-app wiki ([principles.md §5](principles.md#5-user-friendly-beginner-friendly-highly-graphical)). One line each; detailed explanations belong to the wiki content, not here.

| Term                        | Meaning in DFYOM                                                                                                                                                                                                                                                                                |
| --------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Stock                       | Raw material blank a part is cut from; comes from the stock library.                                                                                                                                                                                                                            |
| Working area                | Region of the stock a part's design is constrained to.                                                                                                                                                                                                                                          |
| Part                        | A designed object made of operations and features; a project holds many.                                                                                                                                                                                                                        |
| Operation                   | A single cutting action: facing, pocketing, drilling, profiling, chamfering, line/curve/shape cut, …                                                                                                                                                                                            |
| Feature                     | A named, parametric design element that generates and owns its operations (e.g. a counterbored hole = drilling + counterbore pocket; a pattern) ([features.md](modes/features.md), draft).                                                                                                      |
| Owned operation             | DFYOM term: an operation generated by a feature; its geometry is edited through the feature, its tool field per operation ([features.md](modes/features.md#expansion-and-owned-operations), draft).                                                                                             |
| Feature block               | DFYOM term: the contiguous run of a feature's owned operations in the design order; it moves and is removed as one ([design-v0.4.md](modes/design-v0.4.md#implementation-f1)).                                                                                                                  |
| Counterbore                 | Flat-bottomed, larger-diameter recess coaxial with a hole, so a socket head cap screw sits flush or below the surface.                                                                                                                                                                          |
| Countersink                 | Conical recess at a hole's mouth (typically 82° inch / 90° metric) for a flat head screw.                                                                                                                                                                                                       |
| Chamfer                     | Bevelled edge cut at an angle (usually 45°) instead of a sharp corner; a small one is an edge break.                                                                                                                                                                                            |
| Chamfer mill                | Tool with angled cutting edges for chamfers and countersinks; a V-bit is the router equivalent.                                                                                                                                                                                                 |
| Clearance hole              | Hole slightly larger than a screw's major diameter so the screw passes freely; sizes by fit class (ISO 273 close, normal, loose).                                                                                                                                                               |
| Blind hole                  | Hole that stops at a depth instead of going through the stock; its depth is measured to full diameter.                                                                                                                                                                                          |
| Tap drill                   | Drill size for a hole that will be threaded with a tap, slightly larger than the thread's minor diameter (M3 × 0.5 → 2.5 mm); DFYOM drills it, the thread is tapped by hand.                                                                                                                    |
| Pilot hole                  | Smaller hole drilled first to guide a screw, insert or larger drill.                                                                                                                                                                                                                            |
| Threaded insert             | Metal insert with an internal thread pressed, screwed or melted into wood or plastic; needs a pilot hole of the maker's size.                                                                                                                                                                   |
| Spot drill                  | Short, stiff drill (90° or 120°) that marks a hole's centre so a drill does not wander; also used to chamfer small holes.                                                                                                                                                                       |
| Socket head cap screw       | Screw with a cylindrical head and hex socket (ISO 4762, SHCS); sits in a counterbore.                                                                                                                                                                                                           |
| Head sink                   | DFYOM term: how far a screw head sits below the face in a counterbore or countersink; added to the table head height for the default counterbore depth ([design-v0.4.md](modes/design-v0.4.md#parameters)).                                                                                     |
| Countersunk head screw      | Screw with a conical head (ISO 10642 90°, inch 82°) that sits flush in a countersink; also "flat head screw".                                                                                                                                                                                   |
| Fastener table              | Built-in table of screw sizes with clearance, tap drill, counterbore and countersink sizes from published standards; ISO metric M1.6–M12 ([design-v0.4.md](modes/design-v0.4.md#fastener-table)).                                                                                               |
| Fit class                   | How loose a clearance hole is around its screw: close, normal or loose (ISO 273).                                                                                                                                                                                                               |
| V-bit                       | Router bit with a conical cutting edge of a given included angle (60°, 90°, …); in DFYOM a kind of chamfer mill.                                                                                                                                                                                |
| Included angle              | The full angle between the two cutting edges of a V-bit, chamfer mill, countersink or drill point (twice the half-angle).                                                                                                                                                                       |
| Tip diameter                | Smallest cutting diameter of a chamfer mill or flat-tipped V-bit (0 for a pointed one).                                                                                                                                                                                                         |
| Slant height                | Length of a cone's flank between two diameters; a chamfer's slant runs from the edge Ø to the chamfer Ø, a chamfer mill's cutting edge from its tip to DC.                                                                                                                                      |
| Pitch circle diameter (PCD) | Diameter of the circle through the centres of a bolt circle's holes.                                                                                                                                                                                                                            |
| Clone path                  | DFYOM term: the chain of path rows that places a Clones feature's instances, drawn in the viewport with instance numbers and skipped positions ([features.md](modes/features.md#properties), draft).                                                                                            |
| Path row                    | DFYOM term: one step of a clone path (`grid`, `offset`, `polar`, `arc`, `point`, proposed `along`), starting where the previous row ended ([features.md](modes/features.md#properties), draft).                                                                                                 |
| Pattern                     | In CAD/CAM generally a linear, grid or circular repeat of a feature; in DFYOM such repeats are [Clones](modes/features.md#clones) rows, and "pattern" is reserved for decorative surface patterns (later, with carving; D30, [plans/v0.4.md Q30](plans/v0.4.md#questions-for-the-user), draft). |
| Pattern seed                | The operation or feature a pattern repeats; its first instance (superseded in DFYOM by the Clones source, draft).                                                                                                                                                                               |
| Bolt circle                 | Holes evenly spaced on a pitch circle diameter (PCD) from a start angle; in DFYOM made by a Clones `arc` row.                                                                                                                                                                                   |
| Clones                      | DFYOM term: a feature that repeats its source along a path of positions (count, path rows, skipped positions) as read-only clone instances ([features.md](modes/features.md#clones), draft).                                                                                                    |
| Source (Clones)             | The feature or set of operations nested in a Clones feature; stays editable and is instance 1; every clone follows its edits ([features.md](modes/features.md#source-and-clone-instances), draft).                                                                                              |
| Clone instance              | One repeat of a Clones source at one path position: read-only owned operations, removed only with the Clones feature ([features.md](modes/features.md#source-and-clone-instances), draft).                                                                                                      |
| Span (feature)              | DFYOM term: a feature's nested operations (a Clones source) and its owned block, contiguous in the design order and moved as one ([design-v0.4.md](modes/design-v0.4.md#implementation-f5)).                                                                                                    |
| Dogbone                     | Corner relief cut past an inside corner (along the bisector; T-bone: along one wall) so a square-cornered part fits a routed pocket.                                                                                                                                                            |
| Single-line font            | Font whose glyphs are strokes, not outlines (e.g. Hershey); engraved on the line with one pass.                                                                                                                                                                                                 |
| View cube                   | Viewport widget: a cube with named faces, edges and corners that turn the camera to that view when clicked ([ui-view-cube.md](conventions/ui-view-cube.md), accepted).                                                                                                                          |
| Library window              | The app window for browsing and editing the machine, tool and stock library from every mode ([ui-library-window.md](conventions/ui-library-window.md), accepted).                                                                                                                               |
| Generalized tool            | A tool given only by type and size, e.g. "1/4″ flat end mill" (no lengths, no flute count); a design operation's tool when no specific tool is chosen, resolved to a library tool in plan mode ([design-v0.2.md](modes/design-v0.2.md#operation-tool)).                                         |
| Tool requirement            | What any tool must satisfy to make an operation (type, size limits), e.g. "flat end mill with radius ≤ the corner radius" ([design.md](modes/design.md#generalized-tools)).                                                                                                                     |
| Specific tool               | A tool from the tool library chosen for a design operation, held as a tool snapshot ([design-v0.2.md](modes/design-v0.2.md#data-model)).                                                                                                                                                        |
| Tool lock                   | A design operation's tool chosen by the user: never replaced automatically; if it stops fitting, a warning, never a silent swap ([design-v0.2.md](modes/design-v0.2.md#tool-lock)).                                                                                                             |
| Tool source                 | A plan operation's tool origin: `design` (from the design tool field, re-resolved when it changes) or `plan` (assigned in the plan, kept) ([plan-v0.2.md](modes/plan-v0.2.md#tool-resolution-from-the-design-tool-field)).                                                                      |
| Auto tool choice            | DFYOM term: the tool chosen for an unlocked design operation on Apply: keep the current tool if it fits, else the best fitting library tool, else a generalized tool of a standard size ([design-v0.2.md](modes/design-v0.2.md#auto-choice)).                                                   |
| Face                        | DFYOM term: a planar surface of the stock or of an operation whose outward normal is ±X, ±Y or ±Z (any plane later).                                                                                                                                                                            |
| Face target                 | The face an operation starts from (`on`); it sets the operation's 2D frame and approach direction ([design-v0.2.md](modes/design-v0.2.md#face-targets-generalised-on)).                                                                                                                         |
| Face frame                  | DFYOM term: a face's 2D coordinate frame (origin, u, v, outward normal n); positions are `[u, v]` in it and depth runs along −n ([design-v0.2.md](modes/design-v0.2.md#face-frame)).                                                                                                            |
| Approach direction          | Direction the tool comes from (the face's outward normal); plan mode derives one setup per approach direction on a 3-axis machine.                                                                                                                                                              |
| Tolerance                   | Allowed deviation attached to an operation or surface; loose by default.                                                                                                                                                                                                                        |
| Reference                   | Datum an operation/surface is dimensioned from; part zero by default.                                                                                                                                                                                                                           |
| Reference model             | A 3D model (STL; STEP later) imported for reference only and shown as a ghost on the stock; never changes the part or toolpaths ([reference-model.md](modes/reference-model.md)).                                                                                                               |
| Ghost                       | Translucent display of a reference model in the viewport; never pickable and never part of the geometry ([ui.md](conventions/ui.md#reference-ghost-v02)).                                                                                                                                       |
| STL                         | Triangle-mesh file format (binary or ASCII) without units or B-rep; the unit is guessed on import and can be changed.                                                                                                                                                                           |
| Placement anchor            | The point of a feature's bounding box its position gives: one of nine (corners, edge midpoints, centre) in the face frame ([design-v0.2.md](modes/design-v0.2.md#placement-anchors)).                                                                                                           |
| Setup change                | Refixturing the stock between two setups (flip or turn it, clamp, set the new work zero) before the next setup's program runs.                                                                                                                                                                  |
| Tabs                        | Small bridges left by cutout operations (profile, line/curve/shape cuts) to hold the part in the stock.                                                                                                                                                                                         |
| Part zero                   | Origin of a part's coordinates in design mode ([design.md](modes/design.md#part-and-stock-v01)); set on the machine as the WCS in run mode.                                                                                                                                                     |
| Facing                      | Operation that flattens the top of the stock by removing a thin layer.                                                                                                                                                                                                                          |
| Pocket                      | Recess with walls and a floor, cut to a depth inside a closed boundary.                                                                                                                                                                                                                         |
| Drilling                    | Operation that makes round holes, blind (with a bottom) or through.                                                                                                                                                                                                                             |
| Profile                     | Cut along a closed shape's outline; a through profile with tabs is a cutout.                                                                                                                                                                                                                    |
| Shape                       | A named 2D figure of lines and arcs in a part, placed by operations on a face ([design-v0.3.md](modes/design-v0.3.md#what-a-shape-is), accepted); v0.1/v0.2 rectangles and circles are inline shapes.                                                                                           |
| Shape frame                 | DFYOM term: a shape's own 2D coordinates (x right, y up), laid onto a face frame when an operation places the shape.                                                                                                                                                                            |
| Placed box                  | DFYOM term: the bounding box of a shape after mirror and rotation, in the face frame; placement anchors name its points ([design-v0.3.md](modes/design-v0.3.md#placing-a-shape-on-a-face)).                                                                                                     |
| Start point                 | DFYOM term: where a shape's loop begins for tab positions and wall/corner numbering: its point with the lowest `v`, then the lowest `u`, in the face frame ([design-v0.3.md](modes/design-v0.3.md#tabs-on-shapes)).                                                                             |
| Shape Editor                | The Design view for building a shape from primitives, booleans and line/arc paths with dimensions ([design-v0.3.md](modes/design-v0.3.md#ui-summary), accepted).                                                                                                                                |
| Region                      | Area bounded by closed loops (outer loops and holes) that never cross; what a pocket removes.                                                                                                                                                                                                   |
| Closed / open contour       | A loop that returns to its start (closed) or a chain with two ends (open path); only centreline cuts take open contours.                                                                                                                                                                        |
| Island                      | Material left standing inside a pocket: a hole in the pocket's region, cut around and not over.                                                                                                                                                                                                 |
| Boolean operation           | Combining regions by union, difference (subtract) or intersection.                                                                                                                                                                                                                              |
| Offset curve                | A curve at a constant distance from another; tool radius compensation and pocket rings are offsets.                                                                                                                                                                                             |
| Bulge                       | Arc of a polyline vertex stored as tan(sweep / 4) (positive counter-clockwise, ±1 a half circle), as in DXF and CavalierContours; the 2D port's wire format only ([shapes.md](architecture/shapes.md#2d-model)).                                                                                |
| Tangent arc                 | Arc that continues the previous element's direction, so the joint has no corner.                                                                                                                                                                                                                |
| Obround                     | Slot shape: two half circles joined by straight parallel sides (stadium).                                                                                                                                                                                                                       |
| Biarc                       | Two tangent arcs joined tangentially; used to approximate Bézier curves and ellipses with arcs (G2/G3).                                                                                                                                                                                         |
| Centreline cut              | Profile with the tool centre on the shape (no radius compensation, "on-line"); cuts a groove of the tool's width.                                                                                                                                                                               |
| Rest material               | Material a tool cannot reach (inside corners smaller than its radius, necks narrower than it); removed later by a smaller tool (rest machining).                                                                                                                                                |
| Import report               | Summary of a vector import: elements read and skipped, curves fitted to arcs and their deviation, repairs, units ([design-v0.3.md](modes/design-v0.3.md#svg-import), accepted).                                                                                                                 |
| Fill rule                   | SVG rule for which areas a path fills: `nonzero` (winding number ≠ 0) or `evenodd` (odd winding); the SVG import turns it into outer loops and holes ([shapes.md](architecture/shapes.md#svg-import)).                                                                                          |
| Cusp                        | Point of a curve without a tangent (its derivative vanishes, e.g. the tip of a heart); arc fitting keeps a true corner there.                                                                                                                                                                   |
| Micro corner                | A line far shorter than the chord tolerance left by arc fitting next to a near-cusp, where no biarc fits; merged into its neighbours ([shapes.md](architecture/shapes.md#arc-fitting)).                                                                                                         |
| Snap                        | Pulling a dragged point onto a nearby target (grid, shape point, stock edge, reference section).                                                                                                                                                                                                |
| Reference section           | Outline of the reference model cut by a face plane at a chosen depth; a snap target for recreating a part.                                                                                                                                                                                      |
| Inside corner radius        | Radius of a pocket's vertical inside corners; must be ≥ the end mill's radius. The **inside corners of the cut** are where the material wraps round the tool: a pocket's corners, an outside profile's concave notches.                                                                         |
| Slot width                  | Width of the channel a profile cuts (kerf); at least the tool diameter.                                                                                                                                                                                                                         |
| Plan                        | Ordered sequence of setups that manufactures one or more parts.                                                                                                                                                                                                                                 |
| Setup                       | One fixturing of the stock on a machine: stock + part placement, workholding, probing/zeroing, tool changes, passes.                                                                                                                                                                            |
| Workholding                 | Devices holding the stock (vises, clamps, vacuum table, …); from a library.                                                                                                                                                                                                                     |
| Workholding item            | One device holding the stock in a setup (toe clamp, vise, screw, block, base, surface hold); expands to obstacles ([workholding.md](modes/workholding.md), draft).                                                                                                                              |
| Toe clamp                   | Strap clamp pressing the stock's edge down onto the table, bolted beside the stock; its pad grips a strip of the stock top (strap clamp, hold-down clamp).                                                                                                                                      |
| Machine vise                | Vise bolted to the table that grips the stock between two jaws; the stock sticks out above the jaws by the protrusion.                                                                                                                                                                          |
| Soft jaws                   | Vise jaws of aluminium, plastic or wood, often machined to the part's shape, that do not mark the stock.                                                                                                                                                                                        |
| Fixture plate               | Plate on the table with a grid of threaded or dowel holes for locating and clamping stock; not sacrificial, so cuts must not break through into it.                                                                                                                                             |
| Spoilboard                  | Sacrificial board on the router table; through cuts break slightly into it.                                                                                                                                                                                                                     |
| Hold-down screw             | Screw through the stock's waste into the spoilboard that holds the stock; a keep-out through the whole stock.                                                                                                                                                                                   |
| Surface hold                | Workholding over the stock's bottom face (double-sided tape, vacuum table, glue); holds pieces once they are cut free.                                                                                                                                                                          |
| Keep-out zone               | Area the tool centre may not enter below a height: an obstacle's footprint grown by the tool radius and the margin.                                                                                                                                                                             |
| Safe height                 | Any Z at which rapids clear stock and workholding; DFYOM uses clearance height, retract height and hops over workholding.                                                                                                                                                                       |
| Rapid plane                 | The Z where rapids run horizontally (the retract plane inside an operation, the clearance plane between operations).                                                                                                                                                                            |
| Rapid move                  | Positioning move at the machine's maximum speed (G0), not cutting.                                                                                                                                                                                                                              |
| Link                        | Move from the end of one cutting pass to the start of the next, as a feed move at depth or a retract–rapid–plunge.                                                                                                                                                                              |
| Hop                         | A link or rapid lifted straight up over a workholding item and down again, instead of raising the whole rapid plane.                                                                                                                                                                            |
| Collision check             | Test of every tool move against obstacles (workholding, fixture plate) with the tool's envelope; errors block export.                                                                                                                                                                           |
| Rabbet                      | Step cut along an edge of the stock or part to a partial depth (rebate); in DFYOM a partial-depth outside profile.                                                                                                                                                                              |
| Depth level                 | Depth of a horizontal face of a reference model below a stock face (a floor, a step, a ceiling) ([reference-query.md](modes/reference-query.md), draft).                                                                                                                                        |
| Height map                  | Grid of surface depths seen along one direction (Z-map), used to compare the simulated cut or the part with the reference.                                                                                                                                                                      |
| Simulated cut               | The stock after the tool's swept volume of a program is removed, as a height map per setup direction.                                                                                                                                                                                           |
| Geometric deviation         | Distance between a made or designed surface and the reference surface; positive = material left (under-cut), negative = cut too deep (over-cut) ([deviation.md](modes/deviation.md), draft). Not the tolerance sense of Deviation.                                                              |
| Over-cut / under-cut        | Cutting deeper than the reference surface (gouge) / leaving material above it.                                                                                                                                                                                                                  |
| Pass                        | One toolpath run of a tool (roughing, finishing, …).                                                                                                                                                                                                                                            |
| Air-cutting                 | Tool moving at feed rate without engaging material.                                                                                                                                                                                                                                             |
| DFM                         | Design for Manufacturability.                                                                                                                                                                                                                                                                   |
| gCode                       | Machine instruction language exported per setup and executed in run mode.                                                                                                                                                                                                                       |
| Virtual machine             | Simulated CNC (a GRBL emulator, [grbl.md](architecture/grbl.md#virtual-machine-task-38)) used for automated testing of runs ([conventions/testing.md](conventions/testing.md)).                                                                                                                 |
| Fillet                      | Rounded transition between surfaces; in DFYOM a retained region of a cutting operation.                                                                                                                                                                                                         |
| Floor fillet                | Fillet between a pocket floor and its walls (bottom radius); made with a bull-nose or ball end mill.                                                                                                                                                                                            |
| Round-over                  | Fillet on a convex (top) edge; made with a round-over bit or 3D passes.                                                                                                                                                                                                                         |
| Retained region             | DFYOM term: zone inside an operation's removal region that it deliberately leaves standing (tabs, fillets).                                                                                                                                                                                     |
| Offcut                      | Waste material on the far side of a profile's slot (the stock frame around a cutout, the slug of an opening); held by tabs until they are cut.                                                                                                                                                  |
| Loose piece                 | Piece of material separated from the part and not held by tabs, so it comes free during machining; evaluation warns `dfm.loosePiece` ([geometry.md](architecture/geometry.md#evaluation-checks)).                                                                                               |
| Peck drilling               | Drilling in steps, retracting between them to clear chips; needed for deep holes (`dfm.holeDeep`: depth > 5 × diameter).                                                                                                                                                                        |
| Stock margin                | Distance from a profile's shape to the stock edge; must be at least the slot width, or the slot leaves the stock and the tabs hold nothing.                                                                                                                                                     |
| Offset-loft                 | DFYOM term: solid built from a closed contour offset at a series of (offset, z) levels; makes floor fillets and drill points ([geometry.md](architecture/geometry.md#offset-loft)).                                                                                                             |
| Chord tolerance             | Maximum distance between a true arc and the straight segments that approximate it (sagitta); sets mesh and polyline resolution.                                                                                                                                                                 |
| Part-frame placement        | Placing every mesh vertex into the part frame in float64 before the float32 mesh I/O, so faces of different directions meet exactly ([shapes.md](architecture/shapes.md#implementation-g1)).                                                                                                    |
| Face tile                   | A ≈ 15 mm square piece of a planar stock face or facing floor, built as its own mesh face so later cuts re-triangulate only the tiles they cross; all tiles map to one surface ([shapes.md](architecture/shapes.md#geometry-for-shape-operations)).                                             |
| Overshoot                   | Extension of a removal region beyond the stock (or past an adjoining removal) so solids overlap instead of just touching.                                                                                                                                                                       |
| Carving                     | Machining a 3D relief surface from vector shapes and profiles; expanded into passes in plan mode.                                                                                                                                                                                               |
| Stepover                    | Lateral distance between adjacent passes of a tool.                                                                                                                                                                                                                                             |
| Stepdown                    | Depth of material removed per pass along Z.                                                                                                                                                                                                                                                     |
| Scallop height              | Height of the ridges left between adjacent passes of a rounded tool; limits stepover for a given surface tolerance.                                                                                                                                                                             |
| General tolerance           | Tolerance applied to untoleranced dimensions (ISO 2768 / title block tolerance); inherited in DFYOM.                                                                                                                                                                                            |
| Symmetric tolerance         | Equal upper and lower deviation (`10 ±0.05`).                                                                                                                                                                                                                                                   |
| Bilateral tolerance         | Different upper and lower deviations (`10 +0.1/−0.05`); unilateral when one is 0.                                                                                                                                                                                                               |
| Limit dimensions            | Tolerance stated as min and max values instead of nominal ± deviations; not in v0.1.                                                                                                                                                                                                            |
| Nominal value               | The stated size a tolerance's deviations are measured from.                                                                                                                                                                                                                                     |
| Deviation                   | Signed difference between a limit and the nominal value (upper and lower deviation).                                                                                                                                                                                                            |
| Quantity                    | A value with kind, unit, exact value and optional tolerance, as entered by the user ([quantities.md](architecture/quantities.md)).                                                                                                                                                              |
| Unit system                 | A project's display unit system, metric (mm) or inch.                                                                                                                                                                                                                                           |
| Basic dimension             | GD&T: theoretically exact value toleranced by a feature control frame. Not used in DFYOM.                                                                                                                                                                                                       |
| Engraving                   | Cutting shallow grooves along paths (on-line) or shallow flat-bottom pockets from vector shapes.                                                                                                                                                                                                |
| V-carving                   | Engraving with a V-bit whose depth follows the shape's local width, so corners come out sharp.                                                                                                                                                                                                  |
| Medial axis                 | Centerline of a shape (points equidistant from two or more edges); drives V-carving depth.                                                                                                                                                                                                      |
| Vectorization               | Tracing a raster image into vector paths (also "image tracing").                                                                                                                                                                                                                                |
| Working folder              | Unpacked copy of an open project in app data, kept current after every change; used for crash recovery.                                                                                                                                                                                         |
| Save history                | The last verified archives of a project, kept in app data ([persistence.md](architecture/persistence.md)).                                                                                                                                                                                      |
| Project asset               | A binary file stored in a project as given (v0.2: a reference model's STL), content-addressed by its SHA-256 under `assets/` ([persistence.md](architecture/persistence.md#assets-and-references-v02)).                                                                                         |
| Library                     | Global app data of reusable stock, tools and machines, shared by all projects ([library.md](architecture/library.md)).                                                                                                                                                                          |
| Library snapshot            | Copy of a library item's values stored in a project; parts and plans reference it, never the library item.                                                                                                                                                                                      |
| WCS / work offset           | Work coordinate system (G54–G59): part zero set on the machine; the work offset is its position in machine coordinates.                                                                                                                                                                         |
| Machine coordinates         | Coordinates relative to the machine's home position (G53); independent of any work offset.                                                                                                                                                                                                      |
| Travel                      | Maximum movement of one machine axis (GRBL `$130`–`$132`).                                                                                                                                                                                                                                      |
| Work envelope               | Volume the tool can reach, given by the travel of all axes.                                                                                                                                                                                                                                     |
| Feed rate                   | Speed of the tool through the material along the path (F word, mm/min or in/min).                                                                                                                                                                                                               |
| Plunge rate                 | Feed rate for moving the tool down into the material along Z.                                                                                                                                                                                                                                   |
| Spindle speed               | Rotational speed of the spindle (S word, rpm).                                                                                                                                                                                                                                                  |
| Chip load                   | Thickness of material each cutting edge removes per revolution: feed rate ÷ (spindle speed × flutes).                                                                                                                                                                                           |
| Climb milling               | Cutting where the tool's edge enters the material at maximum chip thickness (tool rotation and feed in the same direction at the cut); better finish.                                                                                                                                           |
| Conventional milling        | Cutting where the edge enters at zero chip thickness (rotation against the feed at the cut); more forgiving on machines with backlash.                                                                                                                                                          |
| Flute                       | Cutting edge and its chip groove on an end mill or drill; the flute count drives chip load.                                                                                                                                                                                                     |
| Flute length                | Length of the cutting part of a tool (LCF); limits cutting depth.                                                                                                                                                                                                                               |
| Stickout                    | Length of a tool protruding from the collet or holder.                                                                                                                                                                                                                                          |
| Flat end mill               | End mill with a flat bottom (corner radius 0).                                                                                                                                                                                                                                                  |
| Ball end mill               | End mill with a hemispherical tip (corner radius = half the diameter).                                                                                                                                                                                                                          |
| Bull-nose end mill          | End mill with a corner radius between 0 and half the diameter (also corner-radius end mill).                                                                                                                                                                                                    |
| Point angle                 | Included angle of a drill tip (typically 118° or 135°).                                                                                                                                                                                                                                         |
| Cutting preset              | Named set of spindle speed, feed rate, plunge rate, stepdown and stepover for a tool, optionally per material ([library.md](architecture/library.md)).                                                                                                                                          |
| Recommended preset          | A cutting preset that follows the feeds-and-speeds calculator for its tool and material class until a value is edited ([library.md](architecture/library.md#recommended-presets)).                                                                                                              |
| Auto mode                   | Plan operation feeds recommended by the feeds-and-speeds calculator instead of fixed preset values; the only mode with locks ([plan-v0.1.md](modes/plan-v0.1.md#locks-and-auto-mode)).                                                                                                          |
| Locked value                | A feeds value the user fixed in auto mode: an input the other recommendations follow (lock the spindle speed and the feed follows); an entered, unlocked value changes only its own field.                                                                                                      |
| Material class              | DFYOM grouping of stock materials (softwood, aluminum, …) used to pick cutting presets.                                                                                                                                                                                                         |
| Toolpath                    | Path the tool center follows (rapids, feeds, arcs, drill cycles); generated in plan mode, turned into gCode by the post-processor.                                                                                                                                                              |
| Post-processor              | Converts toolpaths into the gCode dialect of one controller (v0.1: GRBL).                                                                                                                                                                                                                       |
| Clearance height            | Safe Z for rapids between operations and for tool changes, above stock and workholding.                                                                                                                                                                                                         |
| Retract height              | Lower safe Z for rapids between passes and pecks within one operation.                                                                                                                                                                                                                          |
| Ramp entry                  | Entering the material along a sloped path instead of plunging straight down.                                                                                                                                                                                                                    |
| Helical entry               | Entering the material along a descending circle (helix); also used for helical boring of holes with an end mill.                                                                                                                                                                                |
| Helical boring              | Making a round hole with an end mill smaller than the hole, along a descending circle (helical interpolation, G2/G3 with Z); ends with a full circle at the bottom.                                                                                                                             |
| Z level                     | One depth of a 2.5D toolpath (step-down level): the operation is cut level by level, each at most one stepdown below the previous.                                                                                                                                                              |
| Lead-in / lead-out          | Short move into and out of a finishing pass from already-cleared material, so the tool does not plunge onto the finished wall.                                                                                                                                                                  |
| Tab lift                    | Raising the tool to the tab top wherever it would cut into a tab, in Z levels below the tab top.                                                                                                                                                                                                |
| Peck drilling               | Drilling in steps, retracting between them to clear chips (G83); chip breaking retracts only slightly (G73).                                                                                                                                                                                    |
| Canned cycle                | One gCode word for a whole drilling cycle (G81–G83); not supported by GRBL 1.1, expanded into G0/G1.                                                                                                                                                                                            |
| Finishing allowance         | Material left on walls by roughing passes and removed by a finishing pass (also "stock to leave").                                                                                                                                                                                              |
| Finish stepdown             | Depth per level of the finishing pass on a pocket's walls; by default the full pocket depth in one level.                                                                                                                                                                                       |
| Breakthrough                | Distance a through cut or through hole goes below the stock bottom.                                                                                                                                                                                                                             |
| Zigzag / one-way            | Facing patterns: cut in both directions, or in one direction with a retracted return. An open centreline groove is cut zigzag by level (along, then back one level lower).                                                                                                                      |
| Offset clearing             | Pocket clearing with concentric rings offset from the wall.                                                                                                                                                                                                                                     |
| Ring tree                   | Rings of offset clearing of a region: each node one connected inward offset (outer and island rings), its children the pieces of its own offset by the step ([plan-v0.3.md](modes/plan-v0.3.md#pocket-offset-clearing-of-a-region)).                                                            |
| Adaptive clearing           | Clearing with constant tool engagement (trochoidal-like paths); not in v0.1.                                                                                                                                                                                                                    |
| Tool change                 | Swapping the tool in the spindle; manual in v0.1 (program stop, re-zero Z).                                                                                                                                                                                                                     |
| Design snapshot             | A plan's own copy of a part and its operations; later design edits do not change it ([plan-v0.1.md](modes/plan-v0.1.md#plans-are-snapshots)).                                                                                                                                                   |
| Plan status                 | Lifecycle of a plan: draft, settled design, finalized, in use, archived.                                                                                                                                                                                                                        |
| Stale                       | A plan's copy that differs from the current design or library item; shown, never updated silently (only draft plans follow both).                                                                                                                                                               |
| Plan operation              | One step of a plan's machining order: one design operation (or several equal holes) with one concrete tool, its preset, overrides and pass strategy.                                                                                                                                            |
| Machining order             | Order in which a setup's plan operations run; independent of the design order.                                                                                                                                                                                                                  |
| Rebuild                     | Replacing a plan's design snapshot with the current design; plan operations keep their tools and settings. Deliberate, except for draft plans.                                                                                                                                                  |
| Apply                       | DFYOM term: confirming pending changes (Enter in a field, Cmd/Ctrl+Enter or the "Apply N" button) so the deferred work runs: tool choice, draft plans following, toolpath regeneration; one undo step ([apply.md](architecture/apply.md)).                                                      |
| Pending changes             | DFYOM term: edits committed to the project since its last Apply whose follow-up work has not run yet; counted on the Apply button ([apply.md](architecture/apply.md#pending-changes)).                                                                                                          |
| Kept-current plan           | DFYOM term: a plan, not archived, whose toolpaths were generated (or exported) before; Apply regenerates its stale toolpaths and its plan edits count as pending changes ([apply.md](architecture/apply.md#apply-jobs)).                                                                        |
| Plan-only edit              | Change to an operation in a plan's design snapshot that leaves the project's design unchanged.                                                                                                                                                                                                  |
| Library copy                | A plan's own snapshot of a library item it uses (stock, machine, tool); re-imported per item when the library item changes.                                                                                                                                                                     |
| Override                    | Value set on one plan operation that wins over the tool preset and the calculator (feeds and speeds).                                                                                                                                                                                           |
| Surface speed               | Speed of the cutting edge relative to the material (m/min, SFM); with the diameter it gives the spindle speed.                                                                                                                                                                                  |
| Chip thinning               | Chip thickness smaller than the chip load when the radial engagement is below half the diameter; compensated by a higher feed.                                                                                                                                                                  |
| Axial chip thinning         | Chip thinning of ball and bull-nose tools when the stepdown is below the corner radius; the cutting edge meets the material at a lead angle below 90°.                                                                                                                                          |
| Effective diameter          | Diameter a ball or bull-nose tool actually cuts at for a given stepdown; used instead of the nominal diameter for the spindle speed.                                                                                                                                                            |
| Feed per revolution         | Distance a drill advances per spindle revolution (mm/rev); feed rate = feed per revolution × spindle speed.                                                                                                                                                                                     |
| Material removal rate       | Volume of material removed per minute (MRR): stepover × stepdown × feed rate.                                                                                                                                                                                                                   |
| Unit power                  | Power needed to remove one unit volume of a material per unit time (specific cutting energy, `Kp`); MRR × unit power gives the cutting power.                                                                                                                                                   |
| Machine rigidity            | How stiffly a machine resists cutting forces; a preset from 2020-extrusion hobby frames to cast-iron mills scales suggested depth of cut and feeds ([feeds-speeds.md](architecture/feeds-speeds.md#machine-rigidity-presets)).                                                                  |
| Cutting power               | Power the spindle delivers into the cut (Pc, kW): material removal rate × unit power; checked against the spindle's available power.                                                                                                                                                            |
| Specific cutting force      | Force per unit chip area (kc, N/mm²), the metric form of unit power: kc / 1000 = unit power in W·s/mm³.                                                                                                                                                                                         |
| Spindle load                | Cutting power as a percentage of the power the spindle can deliver at the current speed.                                                                                                                                                                                                        |
| Rubbing                     | Edge sliding over the material instead of cutting because the chip load is too small; heats and dulls the tool.                                                                                                                                                                                 |
| Sender                      | Program that streams gCode to a controller and handles its responses, status reports and realtime commands.                                                                                                                                                                                     |
| Character counting          | GRBL streaming method: the sender keeps the controller's 128-byte RX buffer full by counting unacknowledged bytes.                                                                                                                                                                              |
| Realtime command            | Single byte (`?`, `!`, `~`, ctrl-x, ≥ 0x80) GRBL acts on immediately, wherever it appears in the stream.                                                                                                                                                                                        |
| Feed hold                   | Controlled stop of motion that keeps position; resumed with cycle start (`~`).                                                                                                                                                                                                                  |
| Override                    | Live percentage adjustment of feed, rapid or spindle speed while running.                                                                                                                                                                                                                       |
| Homing                      | Cycle that moves to the limit switches to establish machine coordinates (GRBL `$H`).                                                                                                                                                                                                            |
| Soft limits                 | Controller check that rejects targets outside the travel; needs homing (GRBL `$20`).                                                                                                                                                                                                            |
| Alarm                       | GRBL lock state after a limit, aborted motion or startup with homing enabled; cleared by `$H` or `$X`.                                                                                                                                                                                          |
| Planner buffer              | Controller queue of upcoming motion blocks used for acceleration look-ahead (15 free blocks in GRBL).                                                                                                                                                                                           |
| Junction deviation          | GRBL's cornering model (`$11`): the corner speed is the one whose centripetal acceleration stays within the axis limits on a circle deviating `$11` mm from the corner.                                                                                                                         |
| Look-ahead                  | Planning speeds over the planner buffer so the machine slows only as much as later corners and the final stop need.                                                                                                                                                                             |
| Trapezoidal profile         | Speed over one move: accelerate at a fixed rate, cruise, decelerate (a triangle when the move is too short to reach the feed rate).                                                                                                                                                             |
| Dwell                       | Timed pause with no motion (`G4 P<seconds>`), e.g. to let the spindle reach speed after `M3`.                                                                                                                                                                                                   |
| DRO                         | Digital readout: live display of the axis positions (work and machine coordinates).                                                                                                                                                                                                             |
| `$$` (settings dump)        | GRBL command that prints every `$n=value` setting; DFYOM reads it at connect and imports it into a library machine ([library.md](architecture/library.md#grbl--import)).                                                                                                                        |
| Arc tolerance               | GRBL's `$12`: the largest distance between an arc and the straight chords the controller splits `G2`/`G3` into.                                                                                                                                                                                 |
| Steps per mm                | Motor steps that move an axis 1 mm (GRBL `$100`–`$102`); set by the drive train, changed only when calibrating.                                                                                                                                                                                 |
| Jog                         | Manual move commanded from the sender (GRBL `$J=`), cancellable at once; it does not change the program's modal state.                                                                                                                                                                          |
| Modal state                 | gCode words that stay in effect until changed (motion mode, feed, units, distance mode); the post writes a word only when it changes (**modal suppression**).                                                                                                                                   |
| Machining program           | Controller-neutral blocks of one setup (tool changes, spindle, rapid/feed/arc moves) handed from plan mode to the post-processor ([grbl.md](architecture/grbl.md#input-boundary)).                                                                                                              |
| Tool-change marker          | The comment line `(DFYOM TOOL CHANGE n: name)` followed by `M0`: DFYOM's sender stops there and guides the tool change; other senders pause at `M0`.                                                                                                                                            |
| Soft reset                  | Ctrl-X to GRBL: stops at once and restarts the controller; during motion it raises an alarm because position may be lost.                                                                                                                                                                       |
| Check mode                  | GRBL mode (`$C`) that parses and validates gCode without moving.                                                                                                                                                                                                                                |
| Machine host                | The process (Electron utility process; a worker thread headless) that owns the controller connection, the sender and its clock, so a frozen window never interrupts a run ([run-v0.1.md](modes/run-v0.1.md#processes)).                                                                         |
| Program pause               | A plain `M0` stop in a program (e.g. a manual-spindle prompt): GRBL holds in `Hold:0` until cycle start; DFYOM's run job waits for `run.job.continue`.                                                                                                                                          |
| Time scale                  | How fast the virtual machine runs against real time: 1–100×, or `max` (as fast as the CPU allows while it has work) ([run-v0.1.md](modes/run-v0.1.md#clocks)).                                                                                                                                  |
| Safety door                 | Input that makes GRBL stop motion and the spindle until the door is closed and cycle start is pressed.                                                                                                                                                                                          |
| Expression                  | A quantity entered as arithmetic over numbers and named values (`D/2 ±0.01`, `tool.diameter`); not a datum _reference_ ([quantities.md](architecture/quantities.md#expressions-and-references)).                                                                                                |
| Surface id                  | Stable name of a surface, `<operation id>.<role>` (e.g. `pocket1.floor`, `profile1.tab[0].top`); used by `on` and in formulas.                                                                                                                                                                  |
| Through hole                | A hole that goes through the whole stock; a **blind hole** stops at a depth (flat or drill-point bottom).                                                                                                                                                                                       |
| Design order                | The order of a part's operations; an operation may only reference surfaces of the stock and earlier operations.                                                                                                                                                                                 |
| Dependant                   | An operation whose `on` or a formula references another operation's surface.                                                                                                                                                                                                                    |
