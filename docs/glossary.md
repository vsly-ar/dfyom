# Glossary

Status: draft

Industry-standard terms as used in DFYOM. This list seeds the in-app wiki ([principles.md §5](principles.md#5-user-friendly-beginner-friendly-highly-graphical)). One line each; detailed explanations belong to the wiki content, not here.

| Term                         | Meaning in DFYOM                                                                                                                                                                                                                                                                                                                                                                                                                            |
| ---------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Stock                        | Raw material blank a part is cut from; comes from the stock library or is entered for the project alone (own stock, DF13).                                                                                                                                                                                                                                                                                                                  |
| Stock variant                | A stock item filed under another stock of the library (its parent), e.g. a cut size of a plate; one level only (library.md).                                                                                                                                                                                                                                                                                                                |
| Stock limit                  | A design limit set by the stock (a depth must end above the stock bottom, a tab thinner than the stock); after a stock change an operation that breaks one keeps its value and shows the finding `dfm.stockLimit` (DF95, [design.md](modes/design.md#changing-the-stock-df95)).                                                                                                                                                             |
| Working area                 | Region of the stock a part's design is constrained to.                                                                                                                                                                                                                                                                                                                                                                                      |
| Part                         | A designed object made of operations and features; a project holds many.                                                                                                                                                                                                                                                                                                                                                                    |
| Operation                    | A single cutting action: facing, pocketing, drilling, profiling, chamfering, line/curve/shape cut, …                                                                                                                                                                                                                                                                                                                                        |
| Feature                      | A named, parametric design element that generates and owns its operations (e.g. a counterbored hole = drilling + counterbore pocket; a pattern) ([features.md](modes/features.md), draft).                                                                                                                                                                                                                                                  |
| Owned operation              | DFYOM term: an operation generated by a feature; its geometry is edited through the feature, its tool field per operation ([features.md](modes/features.md#expansion-and-owned-operations), draft).                                                                                                                                                                                                                                         |
| Feature block                | DFYOM term: the contiguous run of a feature's owned operations in the design order; it moves and is removed as one ([design-v0.4.md](modes/design-v0.4.md#implementation-f1)).                                                                                                                                                                                                                                                              |
| Disabled (operation/feature) | DFYOM term: an operation or feature switched off in Design (or in one plan only): kept in the list, left out of the 3D model, DFM, Plan and export; what builds on it is off with it ([design.md](modes/design.md#disabling-operations-and-features-df106)).                                                                                                                                                                                |
| Counterbore                  | Flat-bottomed, larger-diameter recess coaxial with a hole, so a socket head cap screw sits flush or below the surface.                                                                                                                                                                                                                                                                                                                      |
| Countersink                  | Conical recess at a hole's mouth (typically 82° inch / 90° metric) for a flat head screw.                                                                                                                                                                                                                                                                                                                                                   |
| Recessed countersink         | A countersink at the floor of a coaxial recess, so a countersunk head sits below the face; a hole type (`recessedCountersink`, [hole-slots-and-round-corners.md](modes/hole-slots-and-round-corners.md#recessed-countersink-type)). Its **recess** is by default the countersink Ø plus a 0.5 mm **ledge** each side and 2 mm deep; with no ledge the cone cuts the recess floor away (a construction surface).                             |
| Stepped countersink          | DFYOM term: a rough countersink cut as terraces by the hole's own flat end mill (no tool change); each step's top corner lies on the cone so the screw head seats, the cut going up to one terrace past the cone under the head ([design-v0.4.md](modes/design-v0.4.md#stepped-countersink-f7-d41), D41).                                                                                                                                   |
| Chamfer                      | Bevelled edge cut at an angle (usually 45°) instead of a sharp corner; a small one is an edge break.                                                                                                                                                                                                                                                                                                                                        |
| Edge chamfer                 | A chamfer along the edge of a pocket, cutout or outline, cut by a V-bit or chamfer mill following the edge (also contour chamfer; a small one deburrs the edge).                                                                                                                                                                                                                                                                            |
| Chamfer mill                 | Tool with angled cutting edges for chamfers and countersinks; a V-bit is the router equivalent.                                                                                                                                                                                                                                                                                                                                             |
| Chamfer width                | Size of a chamfer: the width of its bevel across the face, from the edge to the bevel's rim; with the angle it names the chamfer ("1.5 × 45°"). DFYOM sizes chamfers by it; depth = width / tan(half the included angle).                                                                                                                                                                                                                   |
| Clearance hole               | Hole slightly larger than a screw's major diameter so the screw passes freely; sizes by fit class (ISO 273 close, normal, loose).                                                                                                                                                                                                                                                                                                           |
| Bolt hole                    | DFYOM feature (internal kind `hole`): a hole for a fastener – simple, counterbored, countersunk or recessed countersunk, sized from the fastener and fit class – that creates its drilling and recess operations; default names "Bolt hole 1", … (dogfood DF17; called "Hole" before) ([features.md](modes/features.md)).                                                                                                                   |
| Blind hole                   | Hole that stops at a depth instead of going through the stock; its depth is measured to full diameter.                                                                                                                                                                                                                                                                                                                                      |
| Tap drill                    | Drill size for a hole that will be threaded with a tap, slightly larger than the thread's minor diameter (M3 × 0.5 → 2.5 mm); DFYOM drills it, the thread is tapped by hand.                                                                                                                                                                                                                                                                |
| Pilot hole                   | Smaller hole drilled first to guide a screw, insert or larger drill.                                                                                                                                                                                                                                                                                                                                                                        |
| Threaded insert              | Metal insert with an internal thread pressed, screwed or melted into wood or plastic; needs a pilot hole of the maker's size.                                                                                                                                                                                                                                                                                                               |
| Spot drill                   | Short, stiff drill (90° or 120°) that marks a hole's centre so a drill does not wander; also used to chamfer small holes.                                                                                                                                                                                                                                                                                                                   |
| Socket head cap screw        | Screw with a cylindrical head and hex socket (ISO 4762, SHCS); sits in a counterbore.                                                                                                                                                                                                                                                                                                                                                       |
| Head sink                    | DFYOM term: how far a screw head sits below the face in a counterbore or countersink; added to the table head height for the default counterbore depth, twice to the head Ø for the default countersink Ø ([design-v0.4.md](modes/design-v0.4.md#parameters)).                                                                                                                                                                              |
| Countersunk head screw       | Screw with a conical head (ISO 10642 90°, inch 82°) that sits flush in a countersink; also "flat head screw".                                                                                                                                                                                                                                                                                                                               |
| Fastener table               | Built-in table of screw sizes with clearance, tap drill, counterbore and countersink sizes from published standards; ISO metric M1.6–M12 ([design-v0.4.md](modes/design-v0.4.md#fastener-table)).                                                                                                                                                                                                                                           |
| Fit class                    | How loose a clearance hole is around its screw: close, normal or loose (ISO 273).                                                                                                                                                                                                                                                                                                                                                           |
| V-bit                        | Router bit with a conical cutting edge of a given included angle (10°–20° for fine engraving, 60°, 90°, …); in DFYOM a kind of chamfer mill (10°–150°).                                                                                                                                                                                                                                                                                     |
| Included angle               | The full angle between the two cutting edges of a V-bit, chamfer mill, countersink or drill point (twice the half-angle).                                                                                                                                                                                                                                                                                                                   |
| Tip diameter                 | Smallest cutting diameter of a chamfer mill or flat-tipped V-bit (0 for a pointed one).                                                                                                                                                                                                                                                                                                                                                     |
| Slant height                 | Length of a cone's flank between two diameters; a chamfer's slant runs from the edge Ø to the chamfer Ø, a chamfer mill's cutting edge from its tip to DC.                                                                                                                                                                                                                                                                                  |
| Pitch circle diameter (PCD)  | Diameter of the circle through the centres of a bolt circle's holes.                                                                                                                                                                                                                                                                                                                                                                        |
| Clone path                   | DFYOM term: the chain of path rows that places a Clones feature's instances, drawn in the viewport with instance numbers and skipped positions ([features.md](modes/features.md#properties), draft).                                                                                                                                                                                                                                        |
| Path row                     | DFYOM term: one step of a clone path (`grid`, `offset`, `polar`, `arc`, `point`, `along` a named shape), starting where the previous row ended ([features.md](modes/features.md#properties), draft).                                                                                                                                                                                                                                        |
| Pattern                      | In CAD/CAM generally a linear, grid or circular repeat of a feature; in DFYOM such repeats are [Clones](modes/features.md#clones) rows, and a **pattern** is a feature that lays copies of a cell shape on a lattice over an area and cuts them with one pocket ([patterns.md](modes/patterns.md), draft).                                                                                                                                  |
| Pattern seed                 | The operation or feature a pattern repeats; its first instance (superseded in DFYOM by the Clones source, draft).                                                                                                                                                                                                                                                                                                                           |
| Pattern area                 | A pattern's boundary (the face, or a named closed shape) less its margin: where cells may go ([patterns.md § Implementation (P2)](modes/patterns.md#implementation-p2)).                                                                                                                                                                                                                                                                    |
| Keep-out (pattern)           | A region inside a pattern's boundary left uncut (a logo, a boss): a `subtract` item of the boundary shape; it grows by the margin.                                                                                                                                                                                                                                                                                                          |
| Clip / whole cells           | A pattern's `fit`: cells crossing the area are left out (whole, the default) or cut to it (clip); clipped fragments under 1 mm wide are dropped as **slivers**.                                                                                                                                                                                                                                                                             |
| Invert (pattern)             | The pocket clears the area minus the cells, so the cells stand as **islands**.                                                                                                                                                                                                                                                                                                                                                              |
| Stacked pattern              | A pattern whose `on` is another pattern's pocket floor: its area is that pattern's cells less the margin, so it is cut only where the lower one cleared (cnc-code's layers; [patterns.md § Implementation (P4)](modes/patterns.md#implementation-p4)).                                                                                                                                                                                      |
| Through pocket               | A pocket cleared down through the opposite stock face plus the breakthrough, so nothing is left in it (no slug); in DFYOM made by a pattern's Through ([patterns.md § Implementation (P4)](modes/patterns.md#implementation-p4)).                                                                                                                                                                                                           |
| Flip (alternate)             | A pattern's `alternate: flip`: every other cell turned 180° about its centre, so triangles nest with the gap as their web ([patterns.md § Implementation (P5)](modes/patterns.md#implementation-p5)).                                                                                                                                                                                                                                       |
| Ghost (pattern)              | A cell drawn dashed in the viewport but not cut: left out at the area's border, or cut or dropped by Clip ([patterns.md § Implementation (P5)](modes/patterns.md#implementation-p5)).                                                                                                                                                                                                                                                       |
| Bottom chamfer (pattern)     | The edge chamfer round a through pattern's cells on the opposite stock face, cut from a flipped setup (chamfer Edges: Bottom or Both; [patterns.md § Implementation (P5)](modes/patterns.md#implementation-p5)).                                                                                                                                                                                                                            |
| Polar lattice                | Cells on concentric rings about the origin, one at the centre; spacing by the cell's circumscribed diameter.                                                                                                                                                                                                                                                                                                                                |
| Radial lattice               | A pattern's `count` cells evenly spaced on one circle of `radius` about the origin, each turned to face out; radial fins are slots on it ([pattern-presets.md § Implementation (H3)](modes/pattern-presets.md#implementation-h3)).                                                                                                                                                                                                          |
| Pattern preset               | A named cell, lattice, gap and Flip picked from the pattern's Presets dialog in one step (Honeycomb, Waffle, Speaker grille …); it sets only those fields ([patterns.md § Implementation (DF107–DF109)](modes/patterns.md#presets-dialog-and-more-presets-df107)).                                                                                                                                                                          |
| Roughing pass                | An optional operation a pocket, an inside/outside profile or a pattern owns (`<id>_roughing`) that clears the bulk with a bigger tool before it, leaving the stock to leave on walls and floor; the owner then cuts only the rest ([roughing.md](modes/roughing.md), [patterns.md § Roughing (DF108)](modes/patterns.md#roughing-df108)).                                                                                                   |
| Stock to leave (roughing)    | The material a roughing pass leaves for its owner: `wall` radially (default the owner's finishing allowance) and `floor` axially (default 0; a through profile's is its skin) ([roughing.md § Stock to leave](modes/roughing.md#stock-to-leave-wall-and-floor)).                                                                                                                                                                            |
| Rest machining               | Machining only the rest material an earlier, bigger tool left: here the pattern's pocket after its roughing pass skips the rings that would cut only cleared air ([patterns.md § Roughing (DF108)](modes/patterns.md#roughing-df108)).                                                                                                                                                                                                      |
| Lattice                      | The arrangement of a pattern's cell positions: square, staggered, hexagonal, polar or radial, with a pitch per direction ([patterns.md](modes/patterns.md#model), draft).                                                                                                                                                                                                                                                                   |
| Cell                         | The shape a [pattern](modes/patterns.md#model) repeats at every lattice node: a primitive or a named closed shape of the part.                                                                                                                                                                                                                                                                                                              |
| Owned shape                  | DFYOM term: a shape generated by a feature (a pattern's `<id>_cells`), hidden from the shape list and edited through the feature ([patterns.md](modes/patterns.md#implementation-p1)).                                                                                                                                                                                                                                                      |
| Web (rib)                    | The material left standing between two neighbouring pattern cells or pockets; a thin web is fragile and makes chamfers meet ([patterns.md](modes/patterns.md#dfm), draft).                                                                                                                                                                                                                                                                  |
| Fin (heatsink)               | A thin wall left standing between two slots of a heatsink to shed heat; in DFYOM the web of a slot pattern ([pattern-presets.md](modes/pattern-presets.md), accepted).                                                                                                                                                                                                                                                                      |
| Pin fin                      | A heatsink pin (square or round) left standing on a grid; in DFYOM an inverted pattern cell ([pattern-presets.md](modes/pattern-presets.md#mapping-onto-the-pattern-model), accepted).                                                                                                                                                                                                                                                      |
| Fin aspect ratio             | Fin thickness to fin height; aluminium fins chatter or bend beyond about 1:8–1:10 (`dfm.patternTallWeb`, [pattern-presets.md](modes/pattern-presets.md#dfm-heatsinks-in-aluminium), accepted).                                                                                                                                                                                                                                              |
| Channel (pin fins)           | The slot between neighbouring pins of a pin-fin heatsink; in DFYOM the gap of an inverted pattern. One tool Ø + 0.5 mm wide lets the second pass finish ([pattern-presets.md](modes/pattern-presets.md#implementation-h2)).                                                                                                                                                                                                                 |
| Slot rule                    | A pocket piece as wide as the tool (a straight slot) is cut once per level along its centre line, entering open ends from outside the stock and ramping into closed ones (square or round ends, H3); no finishing pass ([pattern-presets.md](modes/pattern-presets.md#implementation-h1)).                                                                                                                                                  |
| Full-width slot (slotting)   | A cut as wide as the tool, both sides engaged (climb on one wall, conventional on the other); the heaviest engagement for feeds.                                                                                                                                                                                                                                                                                                            |
| Bolt circle                  | Holes evenly spaced on a pitch circle diameter (PCD) from a start angle; in DFYOM made by a Clones `arc` row.                                                                                                                                                                                                                                                                                                                               |
| Clones                       | DFYOM term: a feature that repeats its source along a path of positions (count, path rows, skipped positions) as read-only clone instances ([features.md](modes/features.md#clones), draft).                                                                                                                                                                                                                                                |
| Clone group (Plan)           | DFYOM term: one plan operation for a clone source operation and all its instances, shown as one row "× N" ([features.md](modes/features.md#clone-groups-in-plan-hardening-df146), draft).                                                                                                                                                                                                                                                   |
| Source (Clones)              | The feature or set of operations nested in a Clones feature; stays editable and is instance 1; every clone follows its edits; since Clones v2 also a group ([features.md](modes/features.md#source-and-clone-instances), draft).                                                                                                                                                                                                            |
| Group (Clones source)        | DFYOM term: a Clones source of several features and plain operations cloned as one unit (`featureIds` + `operationIds`), a Clones among them with its own source (Clones of Clones, two levels at most) ([features.md](modes/features.md#clones-v2-groups-df40)).                                                                                                                                                                           |
| Clone instance               | One repeat of a Clones source at one path position: read-only owned operations, removed only with the Clones feature ([features.md](modes/features.md#source-and-clone-instances), draft).                                                                                                                                                                                                                                                  |
| Mirror row                   | DFYOM term: a Clones path row that adds a mirror image of every instance placed before it across a line parallel to u or v ([clones-mirror.md](modes/clones-mirror.md)).                                                                                                                                                                                                                                                                    |
| Span (feature)               | DFYOM term: a feature's nested operations (a Clones source) and its owned block, contiguous in the design order and moved as one ([design-v0.4.md](modes/design-v0.4.md#implementation-f5)).                                                                                                                                                                                                                                                |
| Dogbone                      | Corner relief cut past an inside corner (along the bisector; T-bone: along one wall) so a square-cornered part fits a routed pocket.                                                                                                                                                                                                                                                                                                        |
| Single-line font             | Font whose glyphs are strokes, not outlines (e.g. Hershey); engraved on the line with one pass.                                                                                                                                                                                                                                                                                                                                             |
| View cube                    | Viewport widget: a cube with named faces, edges and corners that turn the camera to that view when clicked ([ui-view-cube.md](conventions/ui-view-cube.md), accepted).                                                                                                                                                                                                                                                                      |
| Library window               | The app window for browsing and editing the machine, tool and stock library from every mode ([ui-library-window.md](conventions/ui-library-window.md), accepted).                                                                                                                                                                                                                                                                           |
| Generalized tool             | A tool given only by type and size, e.g. "1/4″ flat end mill" (no lengths, no flute count); a design operation's tool when no specific tool is chosen, resolved to a library tool in plan mode ([design-v0.2.md](modes/design-v0.2.md#operation-tool)).                                                                                                                                                                                     |
| Tool requirement             | What any tool must satisfy to make an operation (type, size limits), e.g. "flat end mill with radius ≤ the corner radius" ([design.md](modes/design.md#generalized-tools)).                                                                                                                                                                                                                                                                 |
| Specific tool                | A tool from the tool library chosen for a design operation, held as a tool snapshot ([design-v0.2.md](modes/design-v0.2.md#data-model)).                                                                                                                                                                                                                                                                                                    |
| Tool lock                    | A design operation's tool chosen by the user: never replaced automatically; if it stops fitting, a warning, never a silent swap ([design-v0.2.md](modes/design-v0.2.md#tool-lock)).                                                                                                                                                                                                                                                         |
| Tool source                  | A plan operation's tool origin: `design` (from the design tool field, re-resolved when it changes) or `plan` (assigned in the plan, kept) ([plan-v0.2.md](modes/plan-v0.2.md#tool-resolution-from-the-design-tool-field)).                                                                                                                                                                                                                  |
| Auto tool choice             | DFYOM term: the tool chosen for an unlocked design operation on Apply: keep the current tool if it fits, else the best fitting library tool, else a generalized tool of a standard size ([design-v0.2.md](modes/design-v0.2.md#auto-choice)).                                                                                                                                                                                               |
| Face                         | DFYOM term: a planar surface of the stock or of an operation whose outward normal is ±X, ±Y or ±Z (any plane later).                                                                                                                                                                                                                                                                                                                        |
| Face target                  | The face an operation starts from (`on`); it sets the operation's 2D frame and approach direction ([design-v0.2.md](modes/design-v0.2.md#face-targets-generalised-on)).                                                                                                                                                                                                                                                                     |
| Face frame                   | DFYOM term: a face's 2D coordinate frame (origin, u, v, outward normal n); positions are `[u, v]` in it and depth runs along −n ([design-v0.2.md](modes/design-v0.2.md#face-frame)).                                                                                                                                                                                                                                                        |
| u, v (face axes)             | The two axes of a face frame: seen from outside the face, u points right and v up. On the top face they are X and Y, so fields there say X and Y; on other faces they say u and v.                                                                                                                                                                                                                                                          |
| Approach direction           | Direction the tool comes from (the face's outward normal); plan mode derives one setup per approach direction on a 3-axis machine.                                                                                                                                                                                                                                                                                                          |
| Tolerance                    | Allowed deviation attached to an operation or surface; loose by default.                                                                                                                                                                                                                                                                                                                                                                    |
| Reference                    | Datum an operation/surface is dimensioned from; part zero by default.                                                                                                                                                                                                                                                                                                                                                                       |
| Reference model              | A 3D model (STL; STEP later) imported for reference only and shown as a ghost on the stock; never changes the part or toolpaths ([reference-model.md](modes/reference-model.md)).                                                                                                                                                                                                                                                           |
| Ghost                        | Translucent display of a reference model in the viewport; never pickable and never part of the geometry ([ui.md](conventions/ui.md#reference-ghost-v02)).                                                                                                                                                                                                                                                                                   |
| STL                          | Triangle-mesh file format (binary or ASCII) without units or B-rep; the unit is guessed on import and can be changed.                                                                                                                                                                                                                                                                                                                       |
| Placement anchor             | The point of a feature's bounding box its position gives: one of nine (corners, edge midpoints, centre) in the face frame ([design-v0.2.md](modes/design-v0.2.md#placement-anchors)).                                                                                                                                                                                                                                                       |
| Setup change                 | Refixturing the stock between two setups (flip or turn it, clamp, set the new work zero) before the next setup's program runs.                                                                                                                                                                                                                                                                                                              |
| Datum edge                   | An edge or face machined (or chosen) as the reference later setups locate from, e.g. two square edges milled in the first setup.                                                                                                                                                                                                                                                                                                            |
| Alignment point              | DFYOM term: a point, edge or hole that exists on the stock when a setup starts (a stock corner or edge, or cut by an earlier setup), with its expected position in the setup's WCS; the spindle points at it in Run so the operator can line the stock up ([alignment.md](modes/alignment.md)).                                                                                                                                             |
| Alignment aid                | DFYOM term: a plan-only operation that is not part of the design, cut only so a later setup can align, e.g. a witness mark or a registration hole ([alignment.md](modes/alignment.md#alignment-aids)).                                                                                                                                                                                                                                      |
| Alignment step               | DFYOM term: the part of a setup change in Run where, after zeroing, the spindle (off) points at a safe height at the work zero and each alignment point in turn; the operator adjusts the stock by hand until all line up, then confirms. Nothing is measured ([alignment.md](modes/alignment.md)).                                                                                                                                         |
| Alignment check              | DFYOM term: in Run after the X/Y zero, the bit moved to the stock's corners or edge ends at a gap outside the plan's outline (or traced round it), so the operator sees whether the stock is square to the axes; with a probe, two points on an edge give its angle and how far to nudge which corner. Nothing is rotated or written ([alignment.md § Check alignment](modes/alignment.md#check-alignment-rv6)).                            |
| Setup work zero              | DFYOM term: the X/Y point of a setup where the operator sets G54 X0 Y0, given in the setup frame as an offset from the front-left corner of the up face (the default) or as one of the setup's alignment points; anywhere by the user's choice, so parts may lie in negative work X/Y too; Z0 always stays on the up face ([alignment.md](modes/alignment.md#setup-work-zero-q61)).                                                         |
| Witness mark                 | Small mark cut on purpose (often a V-bit spot or short line) so a later setup can be lined up to it by eye or by touch.                                                                                                                                                                                                                                                                                                                     |
| Registration hole            | Hole cut on purpose to locate the stock between setups: a dowel pin in it and in a matching hole in the spoilboard or fixture fixes the stock's position after a flip or shift.                                                                                                                                                                                                                                                             |
| Dowel pin (registration pin) | Precision cylindrical pin pressed into registration holes to locate the stock (or two parts) repeatably.                                                                                                                                                                                                                                                                                                                                    |
| Two-sided machining          | Machining a part from the top, flipping it about an axis (X or Y), and machining the bottom in a second setup located from the first.                                                                                                                                                                                                                                                                                                       |
| Flip axis                    | The line on the stock's top that the stock is turned over about in two-sided machining; registration holes and their dowels go on it, so the flipped stock drops onto the same dowels ([alignment.md S25](modes/alignment.md#implementation-follow-ups-q106q108)).                                                                                                                                                                          |
| Tiling                       | Machining a stock larger than the machine's working area in several setups (tiles), shifting the stock between them and splitting the toolpaths by tile.                                                                                                                                                                                                                                                                                    |
| Tile                         | One setup of a tiled job: the part of the stock inside the travel at one stock position, with its share of the toolpaths.                                                                                                                                                                                                                                                                                                                   |
| Tile overlap                 | Strip of the stock that two neighbouring tiles both reach; holds the alignment points and absorbs positioning error at the seam.                                                                                                                                                                                                                                                                                                            |
| Indexing (stock)             | Moving the stock by a known step between tiles or setups and locating it again (pins, fence, marks), so coordinates carry over.                                                                                                                                                                                                                                                                                                             |
| Edge finder                  | Spindle-mounted tool (mechanical wobbler or electronic) that finds a stock edge in X or Y; its radius is added to set the work zero.                                                                                                                                                                                                                                                                                                        |
| 3D touch probe               | Spindle-mounted probe with a ball stylus that signals contact in X, Y and Z; with `G38.2` it finds edges, corners, hole centres and surfaces.                                                                                                                                                                                                                                                                                               |
| Two-point alignment          | Measuring two points of a known reference line to compute the stock's rotation (angle) and offset; with three or more points a best fit with a residual (skew compensation).                                                                                                                                                                                                                                                                |
| Skew compensation            | Turning a program by the measured stock angle about the work zero so it lines up with a stock that is not square to the machine axes; on GRBL done in the post or sender, since GRBL has no `G68`.                                                                                                                                                                                                                                          |
| Split line                   | DFYOM term: a vertical cut across a part (straight in phase 4a, along a shape since 4e) where it is divided into pieces cut from separate stocks and assembled ([split-parts.md](modes/split-parts.md)).                                                                                                                                                                                                                                    |
| Shape line (split)           | DFYOM term: a split line along an open named shape of the part, from edge to edge (polyline or curve); its pieces are general regions, keyed on its straight segments only ([split-parts.md § Implementation (4e)](modes/split-parts.md#implementation-4e)).                                                                                                                                                                                |
| Split level                  | DFYOM term: a horizontal cut at a Z through a part, dividing it into layers cut from separate stocks and glued (stack lamination) ([split-parts.md](modes/split-parts.md)).                                                                                                                                                                                                                                                                 |
| Piece (split)                | DFYOM term: one cell of a split part, a derived part with its own blank that follows the source part's edits ([split-parts.md](modes/split-parts.md#source-and-pieces)).                                                                                                                                                                                                                                                                    |
| Blank (piece)                | The stock a piece is cut from: the piece bounds plus a margin per side, or a library stock that holds them.                                                                                                                                                                                                                                                                                                                                 |
| Butt joint                   | Two flat faces glued together with no interlocking geometry; often reinforced with dowels.                                                                                                                                                                                                                                                                                                                                                  |
| Glue face                    | The faces two pieces of a split meet and are glued on: the cut along a split line or level, less what the part removes there ([split-parts.md](modes/split-parts.md#dfm-near-a-split)).                                                                                                                                                                                                                                                     |
| Dowel joint                  | Butt joint aligned and strengthened by dowels in matching blind holes in both glue faces; in DFYOM the joint of split levels, each hole 0.2 mm larger than its dowel ([split-parts.md § Implementation (4b)](modes/split-parts.md#implementation-4b)).                                                                                                                                                                                      |
| Half-lap joint               | Joint where each piece keeps half the thickness over an overlap, so the laps sit on each other flush.                                                                                                                                                                                                                                                                                                                                       |

| WCS / work offset            | Work coordinate system (G54–G59): part zero set on the machine; the work offset is its position in machine coordinates.                                                                                                                                                                                                                                                                                                                     |
| Machine coordinates          | Coordinates relative to the machine's home position (G53); independent of any work offset.                                                                                                                                                                                                                                                                                                                                                  |
| Travel                       | Maximum movement of one machine axis (GRBL `$130`–`$132`).                                                                                                                                                                                                                                                                                                                                                                                  |
| Work envelope                | Volume the tool can reach, given by the travel of all axes.                                                                                                                                                                                                                                                                                                                                                                                 |
| Feed rate                    | Speed of the tool through the material along the path (F word, mm/min or in/min).                                                                                                                                                                                                                                                                                                                                                           |
| Plunge rate                  | Feed rate for moving the tool down into the material along Z.                                                                                                                                                                                                                                                                                                                                                                               |
| Spindle speed                | Rotational speed of the spindle (S word, rpm).                                                                                                                                                                                                                                                                                                                                                                                              |
| Chip load                    | Thickness of material each cutting edge removes per revolution: feed rate ÷ (spindle speed × flutes).                                                                                                                                                                                                                                                                                                                                       |
| Climb milling                | Cutting where the tool's edge enters the material at maximum chip thickness (tool rotation and feed in the same direction at the cut); better finish.                                                                                                                                                                                                                                                                                       |
| Conventional milling         | Cutting where the edge enters at zero chip thickness (rotation against the feed at the cut); more forgiving on machines with backlash.                                                                                                                                                                                                                                                                                                      |
| Flute                        | Cutting edge and its chip groove on an end mill or drill; the flute count drives chip load.                                                                                                                                                                                                                                                                                                                                                 |
| Flute length                 | Length of the cutting part of a tool (LCF); limits cutting depth.                                                                                                                                                                                                                                                                                                                                                                           |
| Overall length (OAL)         | Whole length of a tool, shank included; bounds the stickout (which must be shorter). In DFYOM a secondary field of a library tool (Details), the stickout is the one people set ([ui-library-window.md](conventions/ui-library-window.md#tool-details-df1)).                                                                                                                                                                                |
| Stickout                     | Length of a tool protruding from the collet or holder. DFYOM shows each tool run's **minimum stickout** (deepest cut + 5 mm for the collet nut, DF130) where the tool is set up and warns only when the stickout is shorter.                                                                                                                                                                                                                |
| Deflection factor            | (stickout / needed stickout)³: how much more a tool bends than it would chucked as short as the cut allows.                                                                                                                                                                                                                                                                                                                                 |
| Shank                        | Uncut cylindrical part of a tool above the flutes, gripped by the collet; it rubs a wall cut deeper than the flute length unless it is reduced.                                                                                                                                                                                                                                                                                             |
| Spindle nose                 | Lower face of the spindle or router at the collet nut, where stickout is measured from. DFYOM's machine stores its distance to the table with Z homed for the Z headroom check (DF68).                                                                                                                                                                                                                                                      |
| Collet nut                   | Threaded nut that closes an ER or router collet on the tool shank; its face is the spindle nose. Its diameter and length are part of the [tool holder](modes/tool-holder.md) model (DF132).                                                                                                                                                                                                                                                 |
| Tool holder                  | What holds the tool in the spindle: collet, collet nut, and the spindle or router body above it. In DFYOM a nut and a body cylinder per machine (the machine's `holder`, from a preset or measured; a library tool may carry its own, DF132 H6), with which the tool becomes a stepped collision envelope ([tool-holder.md](modes/tool-holder.md)).                                                                                         |
| Flat end mill                | End mill with a flat bottom (corner radius 0).                                                                                                                                                                                                                                                                                                                                                                                              |
| Ball end mill                | End mill with a hemispherical tip (corner radius = half the diameter).                                                                                                                                                                                                                                                                                                                                                                      |
| Tapered ball end mill        | Ball end mill whose ball tip sits on a cone that widens to the shank (tapered ball nose, tapered carving bit); quoted by tip radius and taper angle per side ([tapered-ball-nose.md](modes/tapered-ball-nose.md)); type `taperedBallEndMill`.                                                                                                                                                                                               |
| Taper angle                  | Angle of one side of a tapered tool to its axis (per side, half the included angle), as tapered ball end mills are quoted.                                                                                                                                                                                                                                                                                                                  |
| Bull-nose end mill           | End mill with a corner radius between 0 and half the diameter (also corner-radius end mill).                                                                                                                                                                                                                                                                                                                                                |
| Point angle                  | Included angle of a drill tip (typically 118° or 135°).                                                                                                                                                                                                                                                                                                                                                                                     |
| Cutting preset               | Named set of spindle speed, feed rate, plunge rate, stepdown and stepover for a tool, optionally per material ([library.md](architecture/library.md)).                                                                                                                                                                                                                                                                                      |
| Recommended preset           | A cutting preset that follows the feeds-and-speeds calculator for its tool and material class until a value is edited ([library.md](architecture/library.md#recommended-presets)).                                                                                                                                                                                                                                                          |
| Auto mode                    | Plan operation feeds recommended by the feeds-and-speeds calculator instead of fixed preset values; the only mode with locks ([plan-v0.1.md](modes/plan-v0.1.md#locks-and-auto-mode)).                                                                                                                                                                                                                                                      |
| Locked value                 | A feeds value the user fixed in auto mode: an input the other recommendations follow (lock the spindle speed and the feed follows); an entered, unlocked value changes only its own field.                                                                                                                                                                                                                                                  |
| Material band                | DFYOM term (DF61): the material earlier cuts of a plan left over a facing's, pocket's, profile's or hole's whole region, as a top (cleared from its own face) and a bottom (cleared from the opposite face); its toolpath skips the passes wholly in air ([plan-v0.2.md](modes/plan-v0.2.md#material-left-for-later-cuts-df61)).                                                                                                            |
| Material class               | DFYOM grouping of stock materials (softwood, aluminum, …) used to pick cutting presets.                                                                                                                                                                                                                                                                                                                                                     |
| Toolpath                     | Path the tool centre follows (rapids, feeds, arcs, drill cycles); generated in plan mode, turned into gCode by the post-processor.                                                                                                                                                                                                                                                                                                          |
| Post-processor               | Converts toolpaths into the gCode dialect of one controller (v0.1: GRBL).                                                                                                                                                                                                                                                                                                                                                                   |
| Clearance height             | Safe Z for rapids between operations and for tool changes, above stock and workholding.                                                                                                                                                                                                                                                                                                                                                     |
| Retract height               | Lower safe Z for rapids between passes and pecks within one operation.                                                                                                                                                                                                                                                                                                                                                                      |
| Ramp entry                   | Entering the material along a sloped path instead of plunging straight down.                                                                                                                                                                                                                                                                                                                                                                |
| Ramp-back entry              | A Line's entry: go a ramp length ahead along the line, then ramp back down to the pass start within the ramp angle, and cut the pass over the ramp.                                                                                                                                                                                                                                                                                         |
| Helical entry                | Entering the material along a descending circle (helix); also used for helical boring of holes with an end mill.                                                                                                                                                                                                                                                                                                                            |
| Helical boring               | Making a round hole with an end mill smaller than the hole, along a descending circle (helical interpolation, G2/G3 with Z); ends with a full circle at the bottom.                                                                                                                                                                                                                                                                         |
| Z level                      | One depth of a 2.5D toolpath (step-down level): the operation is cut level by level, each at most one stepdown below the previous.                                                                                                                                                                                                                                                                                                          |
| Lead-in / lead-out           | Short move into and out of a finishing pass from already-cleared material, so the tool does not plunge onto the finished wall.                                                                                                                                                                                                                                                                                                              |
| Tab lift                     | Raising the tool to the tab top wherever it would cut into a tab, in Z levels below the tab top.                                                                                                                                                                                                                                                                                                                                            |
| Peck drilling                | Drilling in steps, retracting between them to clear chips (G83); chip breaking retracts only slightly (G73).                                                                                                                                                                                                                                                                                                                                |
| Canned cycle                 | One gCode word for a whole drilling cycle (G81–G83); not supported by GRBL 1.1, expanded into G0/G1.                                                                                                                                                                                                                                                                                                                                        |
| Finishing allowance          | Material left on walls by roughing passes and removed by a finishing pass (also "stock to leave").                                                                                                                                                                                                                                                                                                                                          |
| Finish stepdown              | Depth per level of the finishing pass on a pocket's or profile's walls; by default the full depth in one level, at most the flute length (in wood also at most 2 × D).                                                                                                                                                                                                                                                                      |
| Finishing feed               | Feed rate of a finishing pass: faster than the roughing feed so that radial chip thinning at the finishing allowance still leaves the roughing chip load (DF74).                                                                                                                                                                                                                                                                            |
| Breakthrough                 | Distance a through cut or through hole goes below the stock bottom.                                                                                                                                                                                                                                                                                                                                                                         |
| Cut depth                    | Depth below the stock top a through cut reaches: the material thickness plus the breakthrough; DFYOM shows it linked to the breakthrough for through profiles ([ui.md](conventions/ui.md#plan-mode-task-37)).                                                                                                                                                                                                                               |
| Through depth                | DFYOM term: the material a through profile or (since DF61) through hole cuts below its stock face: the stock extent less what facings, pockets and blind profiles of the opposite face, cut in an earlier setup, cleared under its whole slot or hole; tabs stand on it ([plan-v0.2.md](modes/plan-v0.2.md#material-removed-by-earlier-setups)).                                                                                            |
| Zigzag / one-way             | Facing patterns: cut in both directions, or in one direction with a retracted return. An open centreline groove is cut zigzag by level (along, then back one level lower).                                                                                                                                                                                                                                                                  |
| Offset clearing              | Pocket clearing with concentric rings offset from the wall.                                                                                                                                                                                                                                                                                                                                                                                 |
| Ring tree                    | Rings of offset clearing of a region: each node one connected inward offset (outer and island rings), its children the pieces of its own offset by the step ([plan-v0.3.md](modes/plan-v0.3.md#pocket-offset-clearing-of-a-region)).                                                                                                                                                                                                        |
| Adaptive clearing            | Clearing with constant tool engagement (trochoidal-like paths); not in v0.1.                                                                                                                                                                                                                                                                                                                                                                |
| Tool change                  | Swapping the tool in the spindle; manual in v0.1 (program stop, re-zero Z).                                                                                                                                                                                                                                                                                                                                                                 |
| Tool run                     | Consecutive operations of one setup cut with the same tool; each run starts with a tool change ([plan-v0.4.md](modes/plan-v0.4.md#tool-changes-per-setup-hardening-df66)).                                                                                                                                                                                                                                                                  |
| Design snapshot              | A plan's own copy of a part and its operations; later design edits do not change it ([plan-v0.1.md](modes/plan-v0.1.md#plans-are-snapshots)).                                                                                                                                                                                                                                                                                               |
| Plan status                  | Lifecycle of a plan: draft, settled design, finalized, in use, archived.                                                                                                                                                                                                                                                                                                                                                                    |
| Stale                        | A plan's copy that differs from the current design or library item; shown, never updated silently (only draft plans follow both).                                                                                                                                                                                                                                                                                                           |
| Plan operation               | One step of a plan's machining order: one design operation (or several equal holes) with one concrete tool, its preset, overrides and pass strategy.                                                                                                                                                                                                                                                                                        |
| Machining order              | Order in which a setup's plan operations run; independent of the design order.                                                                                                                                                                                                                                                                                                                                                              |
| Rebuild                      | Replacing a plan's design snapshot with the current design; plan operations keep their tools and settings. Deliberate, except for draft plans.                                                                                                                                                                                                                                                                                              |
| Apply                        | DFYOM term: confirming pending changes (Enter in a field, Cmd/Ctrl+Enter or the "Apply N" button) so the deferred work runs: tool choice, draft plans following, toolpath regeneration; one undo step ([apply.md](architecture/apply.md)).                                                                                                                                                                                                  |
| Pending changes              | DFYOM term: edits committed to the project since its last Apply whose follow-up work has not run yet; counted on the Apply button ([apply.md](architecture/apply.md#pending-changes)).                                                                                                                                                                                                                                                      |
| Auto-apply                   | DFYOM term: Apply run by itself after a set time without edits ("Auto-apply after" setting, 10 s by default, or Off) ([apply.md](architecture/apply.md#auto-apply-df28)).                                                                                                                                                                                                                                                                   |
| Kept-current plan            | DFYOM term: a plan, not archived, whose toolpaths were generated (or exported) before; Apply regenerates its stale toolpaths and its plan edits count as pending changes ([apply.md](architecture/apply.md#apply-jobs)).                                                                                                                                                                                                                    |
| Plan-only edit               | Change to an operation in a plan's design snapshot that leaves the project's design unchanged.                                                                                                                                                                                                                                                                                                                                              |
| Library copy                 | A plan's own snapshot of a library item it uses (stock, machine, tool); re-imported per item when the library item changes.                                                                                                                                                                                                                                                                                                                 |
| Override                     | Value set on one plan operation that wins over the tool preset and the calculator (feeds and speeds).                                                                                                                                                                                                                                                                                                                                       |
| Surface speed                | Speed of the cutting edge relative to the material (m/min, SFM); with the diameter it gives the spindle speed.                                                                                                                                                                                                                                                                                                                              |
| Chip thinning                | Chip thickness smaller than the chip load when the radial engagement is below half the diameter; compensated by a higher feed.                                                                                                                                                                                                                                                                                                              |
| Axial chip thinning          | Chip thinning of ball and bull-nose tools when the stepdown is below the corner radius; the cutting edge meets the material at a lead angle below 90°.                                                                                                                                                                                                                                                                                      |
| Effective diameter           | Diameter a ball or bull-nose tool actually cuts at for a given stepdown; used instead of the nominal diameter for the spindle speed.                                                                                                                                                                                                                                                                                                        |
| Feed per revolution          | Distance a drill advances per spindle revolution (mm/rev); feed rate = feed per revolution × spindle speed.                                                                                                                                                                                                                                                                                                                                 |
| Material removal rate        | Volume of material removed per minute (MRR): stepover × stepdown × feed rate.                                                                                                                                                                                                                                                                                                                                                               |
| Unit power                   | Power needed to remove one unit volume of a material per unit time (specific cutting energy, `Kp`); MRR × unit power gives the cutting power.                                                                                                                                                                                                                                                                                               |
| Feed factor                  | Machinery's Handbook multiplier `C` on the unit power for thin chips (1.6 at .001″ per tooth, 1.0 near .012″); with the tool-wear factor `W` (1.1–1.3) it corrects the cutting power of metals on hobby machines (DF131).                                                                                                                                                                                                                   |
| Machine rigidity             | How stiffly a machine resists cutting forces; a preset from 2020-extrusion hobby frames to cast-iron mills scales suggested depth of cut and feeds ([feeds-speeds.md](architecture/feeds-speeds.md#machine-rigidity-presets)).                                                                                                                                                                                                              |
| Cutting power                | Power the spindle delivers into the cut (Pc, kW): material removal rate × unit power; checked against the spindle's available power.                                                                                                                                                                                                                                                                                                        |
| Cutting jog feed             | The slower jog feed used while the spindle turns, for light cutting by hand with the jog pad (default 600 mm/min; [run-machine.md](modes/run-machine.md#spindle-while-jogging-rv1)).                                                                                                                                                                                                                                                        |
| Specific cutting force       | Force per unit chip area (kc, N/mm²), the metric form of unit power: kc / 1000 = unit power in W·s/mm³.                                                                                                                                                                                                                                                                                                                                     |
| Spindle load                 | Cutting power as a percentage of the power the spindle can deliver at the current speed.                                                                                                                                                                                                                                                                                                                                                    |
| Rubbing                      | Edge sliding over the material instead of cutting because the chip load is too small; heats and dulls the tool.                                                                                                                                                                                                                                                                                                                             |
| Sender                       | Program that streams gCode to a controller and handles its responses, status reports and realtime commands.                                                                                                                                                                                                                                                                                                                                 |
| Character counting           | GRBL streaming method: the sender keeps the controller's 128-byte RX buffer full by counting unacknowledged bytes.                                                                                                                                                                                                                                                                                                                          |
| Realtime command             | Single byte (`?`, `!`, `~`, ctrl-x, ≥ 0x80) GRBL acts on immediately, wherever it appears in the stream.                                                                                                                                                                                                                                                                                                                                    |
| Feed hold                    | Controlled stop of motion that keeps position; resumed with cycle start (`~`).                                                                                                                                                                                                                                                                                                                                                              |
| Override                     | Live percentage adjustment of feed, rapid or spindle speed while running.                                                                                                                                                                                                                                                                                                                                                                   |
| Homing                       | Cycle that moves to the limit switches to establish machine coordinates (GRBL `$H`).                                                                                                                                                                                                                                                                                                                                                        |
| Input pins (`Pn:`)           | The controller inputs active in a GRBL status report: `X`/`Y`/`Z` limit switches, `P` probe, `D` safety door, `H` feed hold, `R` reset (often the emergency stop), `S` cycle start.                                                                                                                                                                                                                                                         |
| Hard limits                  | Controller stop on a limit switch input (GRBL `$21`): any change of a limit pin outside Alarm stops everything at once with `ALARM:1`, and only a reset continues; homing is recommended afterwards ([run-machine.md](modes/run-machine.md#after-a-hard-limit-df134)).                                                                                                                                                                      |
| Soft limits                  | Controller check that rejects targets outside the travel; needs homing (GRBL `$20`).                                                                                                                                                                                                                                                                                                                                                        |
| Homing corner                | DFYOM term: the XY corner of the travel a machine homes to (back right = GRBL's default `$23=0`); Z homes up. Machine coordinates still span −travel…0 ([run.md](modes/run.md#machine-coordinates-and-the-homing-corner-df33)).                                                                                                                                                                                                             |
| Homing direction mask        | GRBL `$23`: one bit per axis (X 1, Y 2, Z 4); a set bit homes that axis towards its negative end.                                                                                                                                                                                                                                                                                                                                           |
| Pull-off                     | Distance the machine backs off a limit switch after homing (GRBL `$27`); the machine position after homing is −pull-off on an axis homing to +.                                                                                                                                                                                                                                                                                             |
| Fixed gantry                 | Router layout where the gantry is fixed to the frame and the table moves under it (Y); stiffer than a moving gantry of the same build.                                                                                                                                                                                                                                                                                                      |
| Alarm                        | GRBL lock state after a limit, aborted motion or startup with homing enabled; cleared by `$H` or `$X`.                                                                                                                                                                                                                                                                                                                                      |
| Planner buffer               | Controller queue of upcoming motion blocks used for acceleration look-ahead (15 free blocks in GRBL).                                                                                                                                                                                                                                                                                                                                       |
| Junction deviation           | GRBL's cornering model (`$11`): the corner speed is the one whose centripetal acceleration stays within the axis limits on a circle deviating `$11` mm from the corner.                                                                                                                                                                                                                                                                     |
| Look-ahead                   | Planning speeds over the planner buffer so the machine slows only as much as later corners and the final stop need.                                                                                                                                                                                                                                                                                                                         |
| Executing line               | The gCode line whose motion the machine is carrying out; behind the acknowledged line by what the planner buffer holds. DFYOM estimates it from `Bf` and the position (run.md DF84).                                                                                                                                                                                                                                                        |
| Trapezoidal profile          | Speed over one move: accelerate at a fixed rate, cruise, decelerate (a triangle when the move is too short to reach the feed rate).                                                                                                                                                                                                                                                                                                         |
| Dwell                        | Timed pause with no motion (`G4 P<seconds>`), e.g. to let the spindle reach speed after `M3`.                                                                                                                                                                                                                                                                                                                                               |
| DRO                          | Digital readout: live display of the axis positions (work and machine coordinates).                                                                                                                                                                                                                                                                                                                                                         |
| `$$` (settings dump)         | GRBL command that prints every `$n=value` setting; DFYOM reads it at connect and imports it into a library machine ([library.md](architecture/library.md#grbl--import)).                                                                                                                                                                                                                                                                    |
| Arc tolerance                | GRBL's `$12`: the largest distance between an arc and the straight chords the controller splits `G2`/`G3` into.                                                                                                                                                                                                                                                                                                                             |
| Steps per mm                 | Motor steps that move an axis 1 mm (GRBL `$100`–`$102`); set by the drive train, changed only when calibrating.                                                                                                                                                                                                                                                                                                                             |
| Jog                          | Manual move commanded from the sender (GRBL `$J=`), cancellable at once; it does not change the program's modal state.                                                                                                                                                                                                                                                                                                                      |
| Modal state                  | gCode words that stay in effect until changed (motion mode, feed, units, distance mode); the post writes a word only when it changes (**modal suppression**).                                                                                                                                                                                                                                                                               |
| Machining program            | Controller-neutral blocks of one setup (tool changes, spindle, rapid/feed/arc moves) handed from plan mode to the post-processor ([grbl.md](architecture/grbl.md#input-boundary)).                                                                                                                                                                                                                                                          |
| Tool-change marker           | The comment line `(DFYOM TOOL CHANGE n: name)` followed by `M0`: DFYOM's sender stops there and guides the tool change; other senders pause at `M0`.                                                                                                                                                                                                                                                                                        |
| Soft reset                   | Ctrl-X to GRBL: stops at once and restarts the controller; during motion it raises an alarm because position may be lost.                                                                                                                                                                                                                                                                                                                   |
| Emergency stop (e-stop)      | Hardware switch that removes power from the spindle and drives without software; DFYOM's Stop and reset are not one ([run.md § Safety](modes/run.md#safety)).                                                                                                                                                                                                                                                                               |
| Real machine                 | A controller DFYOM reaches over a serial port (`target: 'serial'`), as opposed to the virtual machine; stricter run rules apply ([run-machine.md](modes/run-machine.md)).                                                                                                                                                                                                                                                                   |
| Check mode                   | GRBL mode (`$C`) that parses and validates gCode without moving.                                                                                                                                                                                                                                                                                                                                                                            |
| Machine host                 | The process (Electron utility process; a worker thread headless) that owns the controller connection, the sender and its clock, so a frozen window never interrupts a run ([run-v0.1.md](modes/run-v0.1.md#processes)).                                                                                                                                                                                                                     |
| Touch plate                  | Conductive plate of known thickness laid on the stock; a probe move (GRBL `G38.2`) stops on contact to set the work zero Z.                                                                                                                                                                                                                                                                                                                 |
| Probe (probing)              | A move toward a target that stops when the controller's probe input closes (a touch plate on the stock, a probe); GRBL `G38.2`–`G38.5`, reporting the contact as `[PRB:x,y,z:1]`. Probe fail: `ALARM:4` (input already closed) or `ALARM:5` (no contact).                                                                                                                                                                                   |
| Probe cycle                  | A probing sequence along one axis: a fast seek, a back-off and a slow re-probe, then a retract; the contact as a value with its uncertainty ([run-probing.md](modes/run-probing.md#the-cycle-runner-rv3)).                                                                                                                                                                                                                                  |
| Probe scene                  | What closes the virtual machine's probe input: stock boxes, an XYZ corner plate, a hole and a bed height field, probed by the tool as a cylinder or a ball ([grbl.md](architecture/grbl.md#probe-scene-rv3)).                                                                                                                                                                                                                               |
| Plate thickness              | The touch plate's thickness, a machine field: probing sets Z0 at the contact point minus it, so Z0 is the surface under the plate.                                                                                                                                                                                                                                                                                                          |
| Fault injection              | Test hooks that make the virtual machine or the loopback port fail like hardware (pulled cable, hung controller, hard limit, missed probe), so failure paths are tested without a machine ([run-machine.md](modes/run-machine.md#fault-injection-m8)).                                                                                                                                                                                      |
| Touch off                    | Setting an axis's work offset by bringing the tool (or a touch plate under it) to a known surface; DFYOM touches off Z at every tool change.                                                                                                                                                                                                                                                                                                |
| Z reference surface          | The flat, upward surface a tool run touches off Z on: the stock top, or a floor already cut, e.g. a faced top ([z-reference.md](modes/z-reference.md), DF69).                                                                                                                                                                                                                                                                               |
| Touch-off spot               | The X, Y on the Z reference surface where the plan guarantees a flat patch for the tool or the touch plate ([z-reference.md](modes/z-reference.md), DF69).                                                                                                                                                                                                                                                                                  |
| Edge finding                 | Locating a stock edge in X or Y by probing it (`G38.2` with a corner plate, the bit or a 3D probe) or by touching it with the tool (a paper or feeler gauge), to set the work zero from it ([v0.5-run.md](plans/v0.5-run.md#7-assistance-setting-the-work-zero-in-xy), proposed).                                                                                                                                                           |
| Work area                    | The part of the machine travel that is really usable (the spindle clears the gantry, the bed ends), marked after homing and kept per machine with a margin; jogs, Go to and checks stay inside it ([run.md § Work area](modes/run.md#work-area-rv7)).                                                                                                                                                                                       |
| Homing repeatability         | How closely repeated homing cycles return the machine to the same physical position, measured by probing a fixed target after each cycle (spread per axis).                                                                                                                                                                                                                                                                                 |
| Calibration cut              | A small test program cut on a free spot of the stock before the real part to check what the machine and tool really cut: a dimension test (square pocket, square boss, slot measured with calipers → tool Ø, steps/mm, backlash, depth) or a feed ladder (run-calibration.md).                                                                                                                                                              |
| Feed ladder                  | A calibration cut of parallel slots, each at a stepped feed (or stepdown) around the tool's preset; the slot that cut best gives the new preset value.                                                                                                                                                                                                                                                                                      |
| Surface map                  | A grid of probed surface heights (stock top or bed) used for Z compensation; a bed map is kept per machine in machine coordinates, a stock map per setup ([run-surface.md](modes/run-surface.md), RV10; the bed map RV11 not yet). | Z compensation               | Adding the surface map's bilinearly interpolated height to the program's Z along every cutting move (moves split into short segments, arcs linearised) so depths follow an uneven surface ([run-surface.md § Following the map](modes/run-surface.md#following-the-map)); also surface leveling or auto-leveling.                                                                                                                           |
| Calibration cut              | A small test program cut on spare stock to measure what the machine and tool really do (tool diameter, axis scale, backlash, a safe feed) before the real part.                                                                                                                                                                                                                                                                             |
| Run from line                | Restarting a stopped program part-way; DFYOM resumes only at an operation start (its tool change included) with a safe re-entry ("Resume from…"); DF129 extends it to any line, after a generated lead-in (`run.job.start { fromLine }`, [run-recovery.md](modes/run-recovery.md#start-from-a-line)).                                                                                                                                       |
| Resume point                 | A line where a resumed program can enter safely: an operation start or a pass start (the first cut after a retract) ([run-recovery.md](modes/run-recovery.md#choosing-where-to-resume)).                                                                                                                                                                                                                                                    |
| Lead-in (resume)             | The moves DFYOM puts before a resumed program: modal state, retract to the machine top, tool wait, spindle and dwell, X/Y above the start, approach, plunge at feed ([run-recovery.md](modes/run-recovery.md#the-lead-in)); not the lead-in of a finishing pass.                                                                                                                                                                            |
| Run journal                  | DFYOM's on-disk record of the running job (program hash, progress, last position, work offset), kept so a run can be recovered after a lost connection or a crash ([run-recovery.md](modes/run-recovery.md#what-dfyom-keeps)).                                                                                                                                                                                                              |
| Go to                        | Moving the spindle to typed coordinates in the work or machine frame, Z first when going up ([run-goto.md](modes/run-goto.md)).                                                                                                                                                                                                                                                                                                             |
| Program pause                | A plain `M0` stop in a program (e.g. a manual-spindle prompt): GRBL holds in `Hold:0` until cycle start; DFYOM's run job waits for `run.job.continue`.                                                                                                                                                                                                                                                                                      |
| Time scale                   | How fast the virtual machine runs against real time: 1–100×, or `max` (as fast as the CPU allows while it has work) ([run-v0.1.md](modes/run-v0.1.md#clocks)).                                                                                                                                                                                                                                                                              |
| Safety door                  | Input that makes GRBL stop motion and the spindle until the door is closed and cycle start is pressed.                                                                                                                                                                                                                                                                                                                                      |
| Expression                   | A quantity entered as arithmetic over numbers and named values (`D/2 ±0.01`, `tool.diameter`); not a datum _reference_ ([quantities.md](architecture/quantities.md#expressions-and-references)).                                                                                                                                                                                                                                            |
| Surface id                   | Stable name of a surface, `<operation id>.<role>` (e.g. `pocket1.floor`, `profile1.tab[0].top`); used by `on` and in formulas.                                                                                                                                                                                                                                                                                                              |
| Construction surface         | DFYOM term: a referenced surface that later cuts removed from the finished part; references still resolve to its level (its operation × the surface it stands on, down to a stock face), like a CAD datum plane ([construction-surfaces.md](modes/construction-surfaces.md)).                                                                                                                                                               |
| Through hole                 | A hole that goes through the whole stock; a **blind hole** stops at a depth (flat or drill-point bottom).                                                                                                                                                                                                                                                                                                                                   |
| Round (corner radius)        | DFYOM term: a rectangle's corner radius set to half its narrowest side and kept so when sizes change: fully rounded ends ([hole-slots-and-round-corners.md](modes/hole-slots-and-round-corners.md#round-corners-df120)).                                                                                                                                                                                                                    |
| Slotted hole                 | An elongated (long) hole for adjustment: two half circles joined by straight sides. Its **slot length** is the travel between the end centres; **overall** = travel + diameter. A bolt hole option (Slotted), cut as Round pockets ([hole-slots-and-round-corners.md](modes/hole-slots-and-round-corners.md#slotted-holes-df119)).                                                                                                          |
| Design order                 | The order of a part's operations; an operation may only reference surfaces of the stock and earlier operations.                                                                                                                                                                                                                                                                                                                             |
| Dependant                    | An operation whose `on` or a formula references another operation's surface.                                                                                                                                                                                                                                                                                                                                                                |
| Controller PWM range         | The `$31..$30` range GRBL maps `S` onto its spindle PWM output; set apart from the usable spindle speeds only when a speed controller needs it (`spindle.controllerMinSpeed`/`controllerMaxSpeed`, library.md).                                                                                                                                                                                                                             |
